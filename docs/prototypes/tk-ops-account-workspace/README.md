# TK-OPS 账号工作区交互原型

这是账号优先的 PC 端本地交互原型。每个账号拥有独立的定位、知识库、脚本、分镜、拆解任务、批次、媒体工具输出、发布和复盘数据；切换账号后，整个工作区上下文同步切换。

## 本地启动

在 PowerShell 中进入本目录后运行：

```powershell
.\start.ps1
```

也可以手动运行：

```powershell
npm install
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

然后打开 `http://127.0.0.1:4173/`。

构建与账号隔离测试：

```powershell
npm run build
npm test
```

## 可交互范围

- 左下角搜索、切换、添加和管理账号，十个账号级业务页面随账号整体切换。
- 系统级账号管理支持五种状态、六步创建向导、配置复制、归档与恢复演示。
- 系统设置包含可完成的 Provider 向导、模型能力、业务能力路由、Prompt 版本编辑和账号 AI Recipe 继承关系。
- 四步新建批次向导支持主题、固定脚本、已有素材；固定脚本可按段落、行、句子拆分，模型参数来自能力契约。
- 批次详情可查看 AI 节点、模型、知识快照、耗时与失败原因，并演示局部重试、回退和取消。
- 脚本与选题支持结构预览、正文编辑、AI 优化、版本采用和分镜门禁。
- 分镜规划支持脚本修订提示、镜头详情和单镜头局部重试。
- 视频拆解支持五阶段任务、脚本 / 关键词 / 关键帧 / 结构语义表格、视频特点 Tag 以及选择性回流。
- 媒体工具箱包含视频下载、去水印、转码压缩、音频提取、封面关键帧和比例裁切；下载和去水印必须完成素材权利确认。
- 查看账号定位、知识来源、选题、内容版本、发布预检和复盘建议。
- 内容库可追溯 AI 配方、生成版本与来源。
- 切换 Light / Dark 主题。
- 在系统设置中演示加载、错误和正常请求状态，并可切换跨页面零数据场景。
- 支持 `Ctrl + N` 新建批次，`Esc` 关闭浮层。

## 原型边界

- 所有内容均为带明确标识的本地演示数据，不会调用真实发布或 AI 服务。
- 媒体工具不绕过登录、DRM、付费墙或访问控制，只表达合法素材处理流程。
- 本轮不包含剪辑工作台、多轨时间线或手机端适配。
- 本轮未修改生产桌面应用、Runtime、数据库或真实接口。
- 进入生产实现前，需要另立 Runtime API、账号隔离、任务队列和迁移测试计划。
