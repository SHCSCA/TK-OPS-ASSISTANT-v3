## 交互回归

- 两个账号切换后，定位、知识库、批次和内容数据互不残留。
- Focus Lab 新建的批次不会出现在镜头 A 工作区。
- 左下角“添加账号”和“管理账号”均可到达完整交互路径。
- 六步账号向导、五态筛选、配置复制、归档和恢复具有可见状态反馈。
- 主题、固定脚本、已有素材和图生视频根据 Provider 能力生成正确可用或受限状态。
- 固定脚本跳过脚本节点；画面节点失败可查看证据并局部重试、回退或取消。
- 十个账号级导航入口与系统设置均可到达，旧“内容计划”和剪辑工作台入口均不存在。
- 脚本保存后会失去采用状态；重新采用后才能进入分镜，已有分镜显示脚本版本不一致。
- 失败镜头可单独重试，不改变其他镜头状态。
- 视频拆解可查看脚本、关键词证据、真实关键帧和结构表格，并确认回流到脚本、分镜或账号知识库。
- Provider 可完成类型、连接、运行参数、模型发现 / 手动录入、测试与保存五步流程。
- 模型路由会阻断缺模型、未验证契约和适配器能力不匹配；Prompt 编辑支持变量校验与未保存切换守卫。
- 固定脚本可按段落、行、句子拆分并预览前三条；素材输入进入视觉规划节点。
- 零数据场景可跨十个账号页面导航，内容库与批次筛选为空时可直接清除筛选。
- 视频下载向导未确认权利时禁用创建任务；确认后任务进入排队 / 运行链路。
- 媒体任务覆盖排队、运行、正在取消、失败和完成；完成输出进入当前账号内容库。
- 错误状态可显示中文原因和“重试加载”，重试后恢复工作台。
- 批次创建、阶段筛选、异常处理、预览和知识库重新索引均有状态反馈。
- 新建浏览器标签页冷启动后，控制台无应用错误或警告。
- `npm test` 共 33 项，覆盖账号隔离、十入口、脚本采用、分镜修订、拆解语义表格、AI 配置契约、空状态、固定脚本拆分、媒体工具与能力阻断。

## 差异说明

- 使用仓库真实 `tkops.ico`，没有复刻参考图中的临时字母图标。
- 为响应“文字太多、噪音太多”，批次与异常信息密度比参考图更低，这是有意收敛。
- 本地原型使用明确标注的演示数据；真实 Runtime、发布和 AI 长任务不在本次实现范围。
- 本轮浏览器视觉回归覆盖 `1440×900`、`1180×760` 与 `960×640`，并分别检查 Light / Dark、页面级横向溢出和控制台错误。
