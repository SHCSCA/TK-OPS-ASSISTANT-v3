## 1. 背景与问题

当前原型已完成账号级隔离、账号管理和 AI 生成流水线，但上一轮将七入口结构收敛得过度：

- “内容计划”只有内容支柱、选题清单和排期，没有脚本策划、正文、版本和 AI 改写工作面。
- “分镜”只存在于工作台阶段和生成节点中，没有独立规划、校对与确认入口。
- “视频拆解”只作为知识库来源记录，无法完成导入、解析、结果查看和回流。
- 当前没有媒体工具箱；视频链接下载、去水印、转码、音频提取等尚无产品入口。

用户要求恢复项目现有的脚本与选题、分镜规划和视频拆解，并补充内容创作者常用的轻量媒体工具。该范围明显超出上一份已批准规格，因此必须先更新计划和产品真源，再生成新规格和实施。

## 2. 产品结论

### 2.1 账号级主导航

账号切换后，下列所有页面与任务都绑定当前 `account_id`：

```text
工作台
定位与知识
────────
脚本与选题
分镜规划
视频拆解
批量生产
────────
内容库
媒体工具箱
发布
复盘
────────
系统设置
当前账号切换器
```

由七个账号级入口扩展为十个。使用两处分隔线建立阶段，而不是增加长分组标题；在紧凑窗口中只显示图标、Tooltip 和可访问名称。

### 2.2 主链路

```text
定位与知识
  -> 脚本与选题
  -> 分镜规划
  -> 批量生产
  -> 自动合成
  -> 内容库
  -> 发布
  -> 复盘
```

视频拆解是另一条创作入口：

```text
本地视频 / 已授权链接素材
  -> 视频拆解
  -> 脚本文案 + 关键帧 + 内容结构
  -> 选择性写回脚本与分镜
  -> 进入统一批量生产链路
```

媒体工具箱只负责轻量处理，输出回到当前账号内容库，不形成第二套项目或资产模型。

## 3. 页面范围

### 3.1 脚本与选题

恢复为明确的账号级工作面，吸收现有生产页面的真实能力边界：

- 选题池：知识推荐、手动添加、筛选、采用和批量建脚本。
- 策划简报：主题、产品 / 服务、目标用户、视频目的、时长、风格、拍摄条件、语言和禁止内容。
- 脚本工作面：结构化预览与原文编辑两种模式。
- AI 动作：生成、改写、缩短、扩写、变体和标题建议。
- 版本轨迹：保存、采用、比较和恢复；记录定位版本、知识快照和 AI 作业。
- 主动作：`确认脚本并进入分镜`。

默认页面保持低噪音：左侧选题 / 简报摘要，中间脚本正文，版本与 AI 作业进入右侧 Detail Panel。

### 3.2 分镜规划

- 左侧脚本段落锚点，清楚标出当前脚本版本。
- 中间按镜头展示画面、旁白 / 字幕、时长、景别、运动和素材来源。
- 支持 AI 生成、镜头级重生成、顺序调整、保存版本和同步最新脚本。
- 选中镜头后在右侧 Detail Panel 编辑高级字段和查看生成记录。
- 不出现多轨时间线、剪辑轨道或专业剪辑工具。
- 主动作：`确认分镜并进入批量生产`。

### 3.3 视频拆解

- 输入：导入本地视频；从媒体工具箱或当前账号内容库选择视频。
- 阶段：导入 / 元数据、视频解析或转录、分段、结构提取、结果确认。
- 结果：脚本文案、视频关键帧、内容结构三种视图。
- 回流：选择写入脚本、分镜、知识库或三者；覆盖现有版本前必须确认。
- Provider / FFprobe 缺失时展示明确原因、系统设置修复入口和重试。
- 所有结果保留来源视频、模型、版本、耗时和日志证据。

### 3.4 媒体工具箱

首版只做一个工具目录页和统一任务抽屉，不为每个工具增加路由。

| 优先级 | 工具 | 输入 | 输出与回流 |
| --- | --- | --- | --- |
| P0 | 视频链接下载 | 已授权公开链接 | 原视频或平台允许的可用媒体文件，导入当前账号内容库 |
| P0 | 视频去水印 | 自有 / 获授权本地视频 | 裁切、遮罩或画面修复后的新版本 |
| P0 | 视频压缩与转码 | 本地视频 | MP4 / WebM、分辨率与质量预设 |
| P0 | 音频提取 | 本地视频 | MP3 / WAV 音频资产 |
| P0 | 封面与关键帧提取 | 本地视频 | 单张封面或关键帧组 |
| P0 | 比例裁切 | 图片或视频 | 9:16、1:1、16:9 等新资产版本 |
| P1 | 字幕 / 语音提取 | 本地视频 | 字幕文件与转录文本，可送入视频拆解 |
| P1 | 批量媒体整理 | 多个本地文件 | 重命名、归档和元数据摘要 |

工具页默认只显示六个常用工具和最近任务。点击工具后打开轻量向导：选择输入 -> 配置 -> 确认 -> 查看任务；高级参数折叠。

## 4. 权利与安全边界

- 视频下载和去水印只用于用户自有、公共领域或已获授权内容。
- 启动任务前必须确认内容权利；任务记录保存确认时间和来源。
- 不绕过登录、DRM、付费墙、访问控制或平台安全机制。
- 不提供批量抓取账号、规避平台风控或隐藏来源的能力。
- 原型中所有下载、去水印和媒体处理均明确标注为交互演示，不伪装真实成功。
- 生产实现前必须单独审查平台条款、依赖许可证和各地区版权要求。

## 5. 真实能力复用边界

### 5.1 可复用

- `apps/desktop/src/pages/scripts/` 的策划、脚本工作面、版本和 AI 作业结构。
- `apps/desktop/src/pages/storyboards/` 的脚本对照、分镜版本和镜头工作面结构。
- `apps/desktop/src/pages/video/` 与 Runtime 视频拆解的导入、解析、分段、结构提取和项目回流契约。
- 现有 `FFmpeg`、`FFprobe`、资产、任务总线、日志与诊断边界。

### 5.2 新增但本轮仅做原型

- 链接下载适配层及支持来源声明。
- 去水印 / 画面修复策略。
- 统一媒体工具任务模型和工具能力注册表。
- 工具输出自动写入当前账号内容库的接口契约。

不得因为原型展示这些功能，就宣称生产 Runtime 已经可调用。

## 6. 数据与配置边界

生产规格阶段拟新增：

- `MediaToolDefinition`：工具 id、输入类型、输出类型、所需能力、风险等级与可用状态。
- `MediaToolTask`：`account_id`、输入来源、配置快照、状态、进度、输出、错误、日志与权利确认。
- `VideoDeconstructionSource`：本地导入、内容库资产或媒体工具输出的统一来源引用。

所有配置进入统一配置总线；UI 不直接拼 FFmpeg、下载器或模型命令。所有任务通过 Runtime 适配层，具备超时、取消、重试、日志和中文错误反馈。

## 9. 验收标准

| 维度 | 验收要求 |
| --- | --- |
| 可发现性 | 侧栏可直接看到脚本与选题、分镜规划、视频拆解和媒体工具箱 |
| 脚本 | 选题、策划、正文、AI 动作、版本和进入分镜形成闭环 |
| 分镜 | 脚本对照、镜头规划、版本与进入批量生产形成闭环，无时间线 |
| 拆解 | 本地视频可进入阶段流，结果能选择性回流脚本、分镜或知识 |
| 工具箱 | 六个 P0 工具可完成交互向导与任务状态演示，输出进入当前账号内容库 |
| 权利边界 | 下载与去水印明确自有 / 授权要求，不展示绕过访问控制的能力 |
| 账号隔离 | 所有创作数据、拆解来源、工具任务和输出严格随账号切换 |
| 低噪音 | 默认呈现当前对象、主动作和异常，高级配置按需展开 |
| PC 体验 | 宽屏与紧凑窗口均可用，不增加手机端模式 |
| 工程边界 | 模块拆分、统一配置、日志、错误恢复和测试齐全；不修改生产代码 |

## 10. 风险与回退

- **导航变密：** 使用分隔线、紧凑图标态和统一 40–44px 行高；若 1180×760 出现拥挤，优先收紧间距，不隐藏核心入口。
- **脚本与批次重复：** 脚本页负责单条 / 版本，批量生产负责批量执行；两者通过采用版本衔接。
- **视频拆解与下载工具混淆：** 下载只产出资产，拆解才生成语义结果。
- **去水印引发权利风险：** 强制权利确认，限制输入来源，不提供绕过访问控制或批量抓取。
- **工具箱膨胀：** V1 固定六个 P0 工具；P1 只在规格中预留，不在默认页面占位。
- **原型误导真实能力：** 所有未接 Runtime 的动作保持演示标签、延迟、失败与说明，不显示假平台回执。
- **回退点：** 新页面均为独立路由 / 模块；可回退导航和路由映射而不影响已完成的账号管理与 AI 流水线原型。
