# TK-OPS 账号优先批量内容工作区与本地交互原型计划

**状态：** 已完成并交付本地交互原型  
**日期：** 2026-07-19  
**目标平台：** Windows PC 桌面应用，不包含手机端、平板端或触屏适配  
**前置决策：** 账号是整个工作区的数据边界；每个账号拥有独立定位与知识库；移除 AI 剪辑工作台及其时间线编辑能力。

## 1. 目标

把 TK-OPS 从“以时间线剪辑为中枢的 16 页创作工具”重构为“以 TikTok 账号为工作区边界的 AI 批量内容生产与发布工作台”。

本轮交付包含：

1. 对齐产品、UI 和架构文档，消除固定 16 页、剪辑中枢和账号仅作为发布对象的旧定义。
2. 建立账号级定位、知识库、内容计划、生产批次、内容资产、发布与复盘主链。
3. 设计低文字密度、低视觉噪音的 PC 桌面信息架构。
4. 通过 Superdesign 生成三种视觉方向并完成用户选型。
5. 将选定方向实现为仓库内模块化、本地可打开、可交互的前端原型。

本计划不修改生产前端、Runtime、数据库或真实接口。生产落地必须另立实现 plan / spec。

## 2. 已确认的产品边界

### 2.1 账号是工作区边界

- 左下角固定账号切换器是工作区入口，不是普通筛选器。
- 切换账号后，导航、定位、知识库、内容计划、素材、项目、批次、任务、发布配置和复盘数据全部切换。
- 所有账号级实体必须带明确 `account_id`；隔离由 Runtime 服务层和仓储层强制执行，不能只靠前端过滤。
- 切换时必须处理未保存内容、缓存失效、实时订阅重建、任务视图刷新和 AI 上下文清理。
- 上一账号的后台任务可以继续运行，但不会在当前账号工作区显示；切回原账号后才能查看。
- 许可证、Runtime、AI Provider、日志框架和全局配置总线属于系统级能力；账号只保存经过配置总线管理的覆盖项。

### 2.2 每个账号拥有独立知识库

每个账号至少拥有以下独立内容：

- 定位、受众、内容支柱和表达风格。
- 品牌事实、产品资料、视觉资产和发布约束。
- 禁用词、风险边界、常用钩子、CTA 和脚本模板。
- 历史内容、表现反馈、参考内容和对标样本。
- 可追踪的资料来源、索引状态、版本和快照。

AI 生成只能读取当前账号的知识库。跨账号复用必须经过明确的复制操作，不允许共享隐性记忆、检索结果或生成上下文。

### 2.3 移除剪辑工作台

本轮明确移除：

- AI 剪辑工作台主页面和正式路由。
- 手动多轨时间线、拖拽编排、片段裁切、吸附、轨道锁定和复杂属性面板。
- 把“专业剪辑能力”作为产品核心卖点或验收前提。

仍然保留：

- AI 生成脚本、分镜、视频镜头、配音和字幕。
- 基于结构化合成方案的自动拼接、字幕烧录、封面生成、转码和渲染。
- 成片预览、镜头级重生成、版本选择、异常处理和整批重试。
- 用户确认后进入渲染、发布与复盘闭环。

系统内部以 `CompositionSpec` 表达自动合成规则，但不向用户暴露复杂时间线编辑器。

## 3. 目标信息架构

正常工作态的 Sidebar 只显示当前账号的七个核心入口：

```text
当前账号工作区
├── 工作台
├── 定位与知识
├── 内容计划
├── 批量生产
├── 内容库
├── 发布
└── 复盘

Sidebar 底部
├── 系统设置
└── 当前账号切换器
```

说明：

- 首启与许可证向导位于正常工作态之外。
- 账号管理通过左下角账号切换器的弹出层进入，不占用一个高频主导航入口。
- 设备、浏览器实例、执行环境、AI Provider、目录和诊断合并到系统设置的分区中。
- 配音、字幕、渲染和自动化不再分别占用主导航；它们成为批量生产、发布和任务反馈中的配置或执行阶段。
- 视频拆解作为“定位与知识”中的参考内容导入能力，不再形成孤立工具页。

目标正式页面从旧 16 页收敛为以下 8 个页面容器：

| Route ID | 页面 | 账号范围 | 核心职责 |
| --- | --- | --- | --- |
| `setup_license_wizard` | 首启与许可证向导 | 系统级 | 授权、目录初始化、Runtime 健康检查 |
| `account_workspace_home` | 工作台 | 当前账号 | 当前计划、生产批次、待处理异常和下一步动作 |
| `account_strategy_knowledge` | 定位与知识 | 当前账号 | 定位版本、知识来源、规则、案例和检索状态 |
| `account_content_plan` | 内容计划 | 当前账号 | 内容栏目、选题矩阵、节奏和批次入口 |
| `account_batch_production` | 批量生产 | 当前账号 | 批次创建、生成进度、成片预览、异常处理和确认 |
| `account_content_library` | 内容库 | 当前账号 | 项目、成片、脚本、素材、模板和版本归档 |
| `account_publishing` | 发布 | 当前账号 | 发布预检、计划、执行状态、回执和重试 |
| `account_review` | 复盘 | 当前账号 | 结果回看、可执行建议和下一轮计划回流 |

`ai_system_settings` 作为壳层级系统设置面板或独立系统路由存在，但不属于账号内容页面，也不计入账号工作区七个核心入口。

## 4. 核心业务主链

新的主链为：

```text
Account
├── PositioningProfile
├── AccountKnowledgeBase
├── BrandKit
├── ContentPlan
│   └── ProductionBatch
│       └── ContentVariant
│           ├── Script
│           ├── Storyboard
│           ├── CompositionSpec
│           ├── VoiceTrack
│           ├── SubtitleTrack
│           ├── RenderTask
│           └── PublishTask
├── DeviceWorkspace
│   └── ExecutionBinding
└── PerformanceSnapshot
```

批量生产交互主链：

`选择当前账号 -> 读取定位与知识快照 -> 选择内容目标 -> 生成选题矩阵 -> 人工确认 -> 批量生成脚本/分镜/镜头/配音/字幕 -> 自动合成 -> 仅处理异常与低置信结果 -> 确认成片 -> 发布 -> 表现回流知识库与下一轮计划`

每个批次必须记录 `account_id`、定位版本、知识库快照、生成策略版本、Provider 版本和任务日志，确保结果可解释、可复现、可追踪。

## 5. 原型必须覆盖的交互

### 5.1 账号切换

- 左下角显示当前账号头像、名称、平台和简洁状态。
- 点击后弹出可搜索账号列表、最近账号、添加账号和管理入口。
- 切换前处理未保存内容；切换中显示轻量加载态；切换后恢复目标账号最近页面。
- 原型中使用明确标注的演示账号和演示内容，仅用于验证隔离交互，不伪装成真实后端结果。
- 切换后页面标题、定位摘要、知识来源、计划、批次、内容库和发布数据同步变化，不能残留上一账号内容。

### 5.2 定位与知识库

- 定位使用短摘要与版本状态，避免大段说明文字。
- 知识库以来源列表、覆盖状态和最近更新为主，不做指标卡堆叠。
- 支持导入资料、添加规则、查看引用、更新索引和回退版本。
- 对缺失资料、索引失败、来源过期和冲突规则提供清晰恢复路径。

### 5.3 批量生产

- 用批次而不是单个项目作为第一操作对象。
- 创建批次只保留目标、数量、模板、素材来源、发布节奏等必要字段。
- 生成过程展示阶段、进度、失败原因、取消和重试。
- 结果采用紧凑列表与成片预览；默认突出异常项，不要求用户逐条检查全部正常结果。
- 允许镜头级重生成和版本切换，但不提供时间线拖拽或专业剪辑控制。

### 5.4 发布与复盘

- 发布前强制检查账号、真实工作区、素材、时长、字幕和执行环境。
- 发布任务只显示当前账号数据，并提供等待、运行、失败、重试和回执状态。
- 复盘只提供可回流到定位、知识库或内容计划的建议，避免经营后台式图表堆叠。

## 6. 视觉与体验原则

- PC 优先，覆盖 `1440×900` 宽屏和约 `1180×760` 紧凑窗口。
- 默认低文字密度；一个区域只表达一个决策，说明文字按需展开。
- 不堆叠统计卡、长段落、重复标签和大面积状态说明。
- 用留白、对齐、层级、状态色和渐进披露代替持续可见的说明文字。
- 主界面只突出当前账号、当前批次、异常和下一步动作。
- 保留 Light / Dark 双主题，统一使用设计令牌与 CSS Variables。
- 所有关键交互覆盖加载、空、正常、错误、重试、取消和成功反馈。

## 9. 验收标准

| 维度 | 验收要求 |
| --- | --- |
| 产品定位 | 明确为账号定位驱动的 AI 批量内容生产与发布工作台 |
| 账号隔离 | 切换后不残留上一账号的内容、缓存、AI 上下文或任务视图 |
| 知识库 | 每个账号独立，生成结果可追踪到知识快照和来源 |
| 剪辑边界 | 不存在 AI 剪辑工作台、手动时间线或专业剪辑承诺 |
| 导航 | 正常账号工作区只有七个核心入口，账号切换器固定在左下角 |
| 批量生产 | 可演示建批、生成、异常优先审核、预览、重试、确认和发布 |
| 视觉噪音 | 无大段说明、无重复指标卡、无后台式功能堆叠 |
| PC 适配 | `1440×900` 与约 `1180×760` 均无关键控件溢出或错位 |
| 状态反馈 | 加载、空、正常、失败、取消、重试和成功状态可见 |
| 工程边界 | 原型模块化；不修改生产前端、Runtime、数据库或真实接口 |

## 10. 风险与控制

- **移除剪辑后无法形成成片：** 使用结构化 `CompositionSpec` 和受控模板自动合成，保留预览、镜头级重生成与版本选择。
- **账号隔离只停留在 UI：** 后续生产设计必须在服务层、仓储层、缓存键、任务和 WebSocket 主题中统一强制 `account_id`。
- **知识库污染：** 检索索引、快照、生成记录和引用全部账号隔离；跨账号只允许显式复制。
- **页面再次膨胀：** 主导航固定七入口；配音、字幕、渲染、自动化、设备和视频拆解作为流程模块或系统分区存在。
- **视觉继续过载：** Superdesign 先比较三个低噪音锚点，再扩展完整流程；未选定视觉方向不得编码。
- **旧文档回流：** 旧 16 页计划与规格只保留历史记录，并明确标记已被新文档取代。
