# TK-OPS 账号管理与 AI 创作流水线交互原型完善计划

**状态：** 已完成  
**日期：** 2026-07-19  
**批准记录：** 用户于 2026-07-19 回复“批准计划”，并于 2026-07-19 回复“批准规格”  
**目标平台：** Windows PC 桌面应用，不考虑手机端、平板端或触屏适配  
**前置真源：** `docs/PRD.md`、`docs/UI-DESIGN-PRD.md`、`docs/ARCHITECTURE-BOOTSTRAP.md`  
**前置原型：** `docs/prototypes/tk-ops-account-workspace/`  
**本轮性质：** 在已确认的账号优先产品方向上补齐账号管理和 AI 创作能力，不恢复 AI 剪辑工作台或手动时间线。

## 1. 目标

完善现有账号优先原型，使用户能够回答四个关键问题：

1. 我有哪些账号，每个账号是否已经完成真实工作区、定位、知识库和发布环境准备？
2. 当前账号默认使用什么 AI 创作配方，它与系统 Provider 配置是什么关系？
3. 创建一个批次时，AI 将按什么输入模式、知识快照和流水线生成内容？
4. AI 任务执行到哪一步，使用了什么模型，失败后如何局部重试、降级或取消？

本轮继续保持低文字密度和渐进披露。AI 能力进入实际工作流，不新增一个孤立的账号级“AI 工具箱”主导航。

## 2. 当前审计结论

完整证据见：

- `docs/prototypes/tk-ops-account-workspace/audit-2026-07-19-ai-account/audit.md`

关键结论：

- 左下角账号切换器的信息架构正确，但“添加账号”和“管理账号”没有完整流程。
- 当前批量生产只有阶段名称，没有 AI 配方、模型能力、知识快照、成本、耗时和节点恢复信息。
- 系统设置没有 Provider、凭据、能力矩阵、健康检查和默认策略。
- 现有低噪音工作台值得保留；新增能力必须通过向导、预设、抽屉和详情面板逐层展开。

参考资料：

### 3.1 吸收的产品能力

- 主题生成视频、固定脚本生成视频、已有素材辅助和图生视频。
- 脚本、画面、视频、TTS、字幕、BGM、自动合成的可编排流水线。
- 直接模型 API 与可选的 ComfyUI / RunningHub 工作流适配。
- 模型能力声明、历史记录、批任务、进度回调和局部失败恢复。
- 图片、视频、语音、视觉模板和提示词前缀的账号级预设。

### 3.2 不吸收的界面方式

- 不复制 Pixelle-Video 的单页三栏参数堆叠。
- 不在账号页面保存 Provider 密钥或系统代理配置。
- 不把所有模型参数作为开始生成前的必填项。
- 不让高阶模式占据 V1 默认路径。

### 3.3 功能优先级

| 优先级 | 模式 | 原型表达 |
| --- | --- | --- |
| P0 | 主题转视频 | 输入主题与目标，生成脚本后进入统一流水线 |
| P0 | 固定脚本转视频 | 粘贴或导入脚本，跳过脚本生成节点 |
| P0 | 已有素材辅助 | 选择当前账号内容库资产，生成缺失镜头并自动合成 |
| P0 | 图生视频 | 从已选主视觉或分镜图生成视频镜头 |
| P1 | 参考音色与数字人 | 增加授权、同意和安全提示后进入账号配方 |
| P2 | 动作迁移与参考视频生成 | 仅作为能力预留，不进入默认 V1 路径 |

## 4. 账号管理信息架构

账号管理是系统级页面，从 Sidebar 左下角账号弹层进入，不新增账号工作区主导航。

### 4.1 账号列表

每个账号显示：

- 头像、平台、账号名和一句定位。
- 状态：草稿、未绑定、可用、需处理、已归档。
- 真实工作区 / 浏览器 / 执行环境绑定健康。
- 知识库索引健康和最近快照。
- 当前 AI 创作配方摘要。
- 最近使用时间和唯一主动作。

支持：搜索、筛选、切换、添加、编辑、复制配置、归档、恢复。

“复制配置”只复制定位模板、知识库规则结构、AI Recipe 和发布默认值；不复制 TikTok 授权、Provider 密钥、浏览器绑定、内容资产、知识向量、任务记录或发布历史。

### 4.2 添加账号向导

采用六步向导，每步只处理一个决策：

1. 选择平台、填写账号基础身份。
2. 连接真实 PC 工作区、浏览器实例和执行环境。
3. 设置定位、受众、语言、时区与内容约束。
4. 初始化该账号独立知识库并导入首批来源。
5. 从系统已配置能力中选择账号 AI 创作配方。
6. 执行授权、目录、Runtime、Provider 和发布预检后完成。

原型必须覆盖处理中、可用、失败、重试、取消和保存草稿；不能用假绿灯冒充真实绑定成功。

### 4.3 账号详情

使用单页分区或标签，而不是多个新增主路由：

- 概览。
- 身份与定位。
- 连接与工作区。
- 知识库。
- AI 创作档案。
- 发布默认值。
- 数据与归档。

## 5. AI 能力架构与界面落点

AI 分为三个配置层，优先级固定为：

`系统能力与默认值 -> 账号 AI Recipe -> 批次临时覆盖`

### 5.1 系统级 AI 能力中心

放在现有“AI 与系统设置”内，负责：

- Provider Profile：凭据、Base URL、代理、区域和连接测试。
- 能力分组：LLM、图片、视频、TTS、字幕、VLM / 资产分析、Embedding。
- 适配方式：直接 API、OpenAI-compatible、ComfyUI、RunningHub。
- 模型能力矩阵：文生图、文生视频、图生视频、参考图、数字人、原生音频，以及真实支持的时长、比例、分辨率和并发。
- 系统默认、超时、并发、成本阈值、回退顺序和健康检查。

系统凭据只保存在统一配置总线 / 安全存储。账号只引用 `provider_profile_id` 和模型配方，不保存原始密钥。

### 5.2 账号级 AI 创作档案

每个账号独立保存：

- 默认脚本模型、图片模型、视频模型和 TTS 音色。
- 视觉风格、提示词前缀、负面约束和模板。
- 画幅、默认时长、拆分模式、BGM 与字幕偏好。
- 知识库快照策略、成本上限、超时和失败回退。

默认只显示配方名称和五项摘要。高级参数通过右侧抽屉展开，并明确标记“继承系统”“账号覆盖”或“本批次临时覆盖”。

### 5.3 新建批次向导

将当前简单 Dialog 扩展为四步：

1. **输入来源：** AI 主题、固定脚本、已有素材。
2. **内容计划：** 目标、数量、语言、账号知识快照和素材范围。
3. **AI 配方：** 选择账号默认或其他已保存配方；高级设置按需展开。
4. **执行确认：** 展示生成节点、预计时间 / 成本区间、风险项和开始动作。

未配置 Provider、知识库不可用或工作区不健康时，向导应明确阻断原因与修复入口。

### 5.4 批次执行详情

使用一条可扫描的节点流水线：

`主题/脚本 -> 分镜 -> 图片/视频 -> TTS -> 字幕 -> 合成/BGM -> 预览/发布`

每个节点可展开查看：

- Provider、模型、版本和能力模式。
- 状态、进度、耗时、成本和重试次数。
- 输入摘要、输出资产、当前账号和知识快照。
- 取消、局部重试、选择回退模型和局部重生成。

默认只显示状态和异常；详细日志、参数和输入输出放入 Detail Panel，避免首屏视觉污染。

## 10. 验收标准

| 维度 | 验收要求 |
| --- | --- |
| 账号管理 | 左下角可进入完整管理页；添加、编辑、复制配置、归档、恢复均有可见结果 |
| 真实边界 | 原型不伪装真实绑定；生产规格明确账号、工作区和执行环境是真实对象 |
| 账号隔离 | 切换后定位、知识、AI Recipe、内容、批次、任务和发布配置全部切换 |
| AI 可见性 | 用户能看见使用的配方、知识快照、模型、节点状态、耗时、成本与失败原因 |
| 输入模式 | 可创建主题、固定脚本和已有素材三种批次；图生视频进入对应节点 |
| 恢复能力 | 节点支持取消、局部重试、回退模型和局部重生成 |
| 配置继承 | 系统默认、账号覆盖、批次覆盖有清晰标记，密钥不下放到账号 |
| 低噪音 | 默认只呈现当前决策、摘要和异常，高级参数按需展开 |
| PC 体验 | 宽屏与紧凑窗口都可用，不增加手机端导航或触屏模式 |
| 工程边界 | 模块化实现、统一配置、异常日志与测试齐全，不触碰旧壳运行链路 |

## 11. 风险与回退

- **账号管理膨胀成 CRM：** 只管理创作、知识、工作区、AI 配方和发布闭环，不增加粉丝经营、订单或团队协作。
- **AI 设置制造视觉污染：** 默认用配方摘要，复杂参数只在高级抽屉和节点详情中出现。
- **模型差异导致无效选项：** 由 `ModelCapabilityRegistry` 驱动 UI，不硬编码所有模型都支持同一能力。
- **高风险生成模式过早进入主线：** 数字人放在 P1，动作迁移放在 P2，并要求授权与安全提示。
- **直接复制外部实现：** 本轮只吸收产品与架构思路；若生产阶段复用 Apache-2.0 代码，必须单独审查归属、许可证和 NOTICE。
- **原型破坏当前已确认版本：** 改造前保留当前原型可运行基线；新模块可按路由和功能开关回退。

## 12. 不在本轮范围

- 真实 TikTok 登录、授权、发布和平台风控绕过。
- 真实 Provider 密钥写入、计费或长任务执行。
- AI 剪辑工作台、手动多轨时间线和专业剪辑工具。
- 手机端、平板端、触屏和响应式移动导航。
- 订单、商品、收益、团队权限或经营后台。
