# TK-OPS 创作对象主链与内容库分类交互原型设计规格

> 日期：2026-07-19  
> 状态：已批准  
> 对应计划：`docs/superpowers/plans/2026-07-19-creative-item-chain-and-library-taxonomy-prototype.md`  
> 增量基线：`docs/superpowers/specs/2026-07-19-creative-centers-media-toolbox-prototype-design.md`  
> 实现范围：`docs/prototypes/tk-ops-account-workspace/`  
> 目标终端：Windows PC 桌面应用，不考虑手机端  
> 视觉基线：沿用当前原型的极简生产台、Tabler Icons、Light / Dark 设计令牌

## 1. 规格定位

本规格只覆盖上一版原型中断裂的创作主链和内容库分类。未被本规格修改的账号切换、系统设置、AI 能力、媒体工具、发布和复盘交互，继续以增量基线规格为准。

发生冲突时，本规格覆盖增量基线中的以下内容：

- 脚本与选题页面。
- 分镜规划页面。
- 视频拆解结果与回流。
- 批量生产内容队列。
- 内容库页面。
- 上述页面使用的原型数据、状态与组件边界。

本规格批准前禁止修改原型代码；批准后只实现本规格，不扩展主导航，不恢复剪辑工作台。

## 2. 设计结论

### 2.1 主对象

每条准备生产的视频内容统一为一个 `ContentItem`：

```text
ContentItem
├── TopicBrief
├── ScriptVersion[]
├── StoryboardVersion[]
├── SourceReference[]
├── ProductionReference[]
└── AssetReference[]
```

页面不得再分别读取无关联的 topic、script、storyboard、variant 和 library 数据后只靠相同标题拼接。

### 2.2 单条与批量

```text
一个 ContentItem
→ 生成单条视频
→ 创建只有一个 BatchEntry 的 ProductionBatch

多个 ContentItem
→ 加入或创建批次
→ 创建多个 BatchEntry 的 ProductionBatch
```

单条视频和批量生产共享任务、阶段、异常、重试、合成、内容变体和资产归档逻辑。

### 2.3 视频拆解

视频拆解是创作来源，不是生产必经步骤：

```text
视频来源
→ 脚本 / 关键词 / 关键帧 / 结构证据
→ 创建或更新 ContentItem / Knowledge / Asset
→ 回到脚本与选题或分镜规划
```

### 2.4 内容库

内容库使用正交的两层信息：

- 媒体类型：全部、视频、图片、音频、文档。
- 业务用途与来源：成片、素材、脚本、字幕、模板、拆解输出、媒体工具输出、本地导入。

模板和工具输出不是媒体类型，不能与视频、图片并列为主类型。

## 3. 跨页对象关系

```text
手动新建 ─┐
AI 推荐 ──┼→ ContentItem → ScriptVersion → StoryboardVersion
视频拆解 ─┘        │             │                │
                   │             │                ├→ 单条生产 ─┐
                   │             │                └→ 加入批次 ─┤
                   │             │                              ↓
                   │             └──────────────→ ProductionBatch
                   │                                            ↓
                   └──────────────────────────→ ContentVariant / Asset
                                                                ↓
                                                              内容库
```

### 3.1 不可变引用

当内容加入批次时创建 `ContentItemReference`，固定记录：

- `contentItemId`。
- `scriptVersionId`。
- `storyboardVersionId`。
- `knowledgeSnapshotId`。
- `positioningVersionId`。
- `aiRecipeVersionId`。
- 创建时间和来源动作。

运行中的批次不得被后续脚本或分镜修改静默替换。创作页产生新版本时，只提示“生产中仍使用 v3”，由用户主动为未开始队列项更新引用。

## 4. 创作链头部

### 4.1 出现位置

- 脚本与选题页面主容器顶部。
- 分镜规划页面主容器顶部。
- 批量生产选中单条内容时的详情顶部。

不出现在工作台、视频拆解列表或内容库首页，避免把页面导航与对象阶段重复表达。

### 4.2 宽屏结构

```text
┌──────────────────────────────────────────────────────────────────────┐
│ 三步整理混乱提示词  ·  Content 01                  [当前主动作]     │
│ ● 选题 ── ● 脚本 ── ◉ 分镜 ── ○ 生产 ── ○ 成片    [版本/来源]     │
└──────────────────────────────────────────────────────────────────────┘
```

- 高度：`72–80px`。
- 第一行：标题、可选短编号、唯一主动作。
- 第二行：五阶段、状态、版本 / 来源次动作。
- 阶段名称不超过两个汉字；状态详情进入 Tooltip 或 Detail Panel。
- 头部不显示大段描述、统计数字、模型参数或日志。

### 4.3 阶段状态

| 状态 | 视觉 | 可交互性 |
| --- | --- | --- |
| `not_started` | 灰色空心节点 | 可点击已完成的前序阶段 |
| `active` | 青色实心节点 | 当前页面状态 |
| `review` | 紫色细环 + “待确认” | 主动作是确认 |
| `confirmed` | 绿色勾选 | 可返回查看，不自动改版本 |
| `blocked` | 红色感叹号 | 点击打开阻断详情 |
| `completed` | 低饱和绿色勾选 | 点击查看成片或资产 |

### 4.4 主动作映射

| 页面与状态 | 主动作 |
| --- | --- |
| 无 `ContentItem` | 新建选题 |
| 已有选题、无脚本 | AI 生成脚本 |
| 脚本草稿 | 采用此版本 |
| 脚本已采用 | 进入分镜 |
| 无分镜 | AI 生成分镜 |
| 分镜有异常 | 处理异常镜头 |
| 分镜待确认 | 确认分镜 |
| 分镜已确认 | 进入生产 |
| 生产运行中 | 查看生产进度 |
| 已生成成片 | 查看成片 |

## 5. 脚本与选题页面

### 5.1 宽屏布局

```text
┌──────────────────────────────── 创作链头部 ────────────────────────────────┐
├──────────── 选题栏 220–240 ────────────┬──────── 脚本工作面 ───────────────┤
│ 搜索 / 状态筛选                        │ 策划摘要 · 当前版本 · 状态        │
│ 当前选题                               │ 结构预览 / 正文编辑                │
│ 其他选题                               │                                  │
│                                        │                                  │
│ [批量生成脚本]                         │ AI 次动作           [阶段主动作]  │
└────────────────────────────────────────┴──────────────────────────────────┘
```

- 页面级标题不再重复一遍“脚本与选题”卡片标题。
- 创作链头部下方只保留一层工作容器。
- 左侧条目显示标题、内容支柱和阶段状态，不使用含义不清的勾选 / 空心圆。
- 当前账号定位摘要保留在 Detail Panel，不占据左栏底部固定空间。

### 5.2 选题条目

每条固定显示：

- 标题，最多两行。
- 内容支柱，单行截断。
- 阶段短标签：仅选题、脚本草稿、脚本已采用、分镜中、已入批次。
- 异常时显示一个红色状态点和短原因。

点击条目执行 `selectContentItem(contentItemId)`，同时切换脚本、分镜、生产引用和链头部。存在未保存正文时先触发守卫。

### 5.3 新建选题入口

- 没有内容时：页面中心空态和创作链头部都指向同一个“新建选题”动作。
- 已有内容时：创作链头部右侧保持“新建选题”次入口；当前阶段主动作仍由内容状态决定。
- 快捷键：页面内 `Ctrl + N` 打开新建选题；批量生产页的 `Ctrl + N` 仍打开新建批次，不做全局冲突。

### 5.4 新建选题弹层

宽度 `680–720px`，最大高度不超过窗口 `80vh`。不使用四步长向导，使用来源标签 + 内容区 + 固定底部动作。

#### 来源标签

```text
手动创建 | AI 推荐 | 视频拆解
```

切换来源时保留各自未提交输入；关闭弹层时若有输入，提示放弃或继续编辑。

#### 手动创建

默认字段：

| 字段 | 必填 | 控件 | 规则 |
| --- | --- | --- | --- |
| 选题标题 | 是 | 单行输入 | 2–80 字符 |
| 内容支柱 | 是 | 单选下拉 | 来自当前账号定位 |
| 目标受众 | 否 | 可搜索单选 | 默认继承账号定位 |
| 创作角度 | 否 | 多行输入 | 最多 160 字符 |
| 目标时长 | 是 | 单选 Chip | 15 / 30 / 45 / 60 秒 |
| 来源或参考 | 否 | 单行输入 | 文本或已授权来源摘要 |

底部动作：取消、创建选题。创建中按钮显示运行状态并禁止重复提交。

#### AI 推荐

顶部只显示当前账号定位版本、知识快照和数量 `3 / 5 / 10`。点击“生成候选”后进入稳定结果区，每条候选显示：

- 选题标题。
- 内容支柱。
- 推荐角度。
- 推荐依据，最多两行。
- 选择框。

底部主动作是“采用所选选题”。每条候选创建独立 `ContentItem`；第一条自动选中，其余保留在左栏。

#### 视频拆解

左侧或顶部选择已完成拆解任务；结果区显示可创建选题的结构段、关键词组和来源时间段。用户选择一条或多条建议后点击“创建选题”。

创建的 `SourceReference` 必须记录拆解任务、结果类型和证据 ID。

### 5.5 创建成功后的状态

```text
ContentItem.stage = topic_ready
selectedContentItemId = newId
Script workspace = empty
Primary action = AI 生成脚本
```

脚本空态文案：

- 标题：`选题已建立`。
- 说明：`补充策划简报，或按当前账号定位生成第一版脚本。`
- 主动作：`AI 生成脚本`。
- 次动作：`完善简报`。

不得只弹 Toast 后保持原页面不变。

### 5.6 脚本采用与进入分镜

- AI 生成脚本后状态为 `script_draft`。
- 用户编辑并保存会产生新版本，不覆盖原版本。
- “采用此版本”将当前版本标记为 adopted，链头部脚本阶段变为已确认。
- 主动作切换为“进入分镜”。
- 点击后导航到分镜页并保持同一个 `selectedContentItemId`。

## 6. 分镜规划页面

### 6.1 宽屏布局

```text
┌──────────────────────────────── 创作链头部 ────────────────────────────────┐
├──────── 脚本段落 220–240 ────────────┬────────── 镜头工作面 ──────────────┤
│ 采用脚本 v3                          │ 镜头 01                           │
│ 01 Hook                              │ 镜头 02 · 异常                    │
│ 02 Body                              │ 镜头 03                           │
│ 03 CTA                               │                                  │
│                                      │                  [阶段主动作]     │
└──────────────────────────────────────┴────────────────────────────────────┘
```

### 6.2 页面进入规则

- 没有当前内容：显示“选择内容”空态，可返回脚本与选题。
- 脚本未采用：显示阻断卡，主动作“返回采用脚本”。
- 已采用脚本、无分镜：显示生成空态。
- 有分镜：显示镜头卡和版本状态。
- 当前分镜引用旧脚本：顶部显示低高度同步提示，不自动重建。

### 6.3 镜头状态与主动作

| 条件 | 主动作 | 是否可确认 |
| --- | --- | --- |
| 没有分镜 | AI 生成分镜 | 否 |
| 正在生成 | 生成中 | 否 |
| 有失败镜头 | 处理异常镜头 | 否 |
| 所有必需镜头就绪 | 确认分镜 | 是 |
| 已确认 | 进入生产 | 已确认 |
| 脚本版本不一致 | 同步脚本并重建 | 否 |

“重新生成分镜”移入更多菜单，不能长期占据唯一主动作。

### 6.4 确认分镜

确认前展示紧凑摘要：

- 镜头数和总时长。
- 采用脚本版本。
- 分镜版本。
- 素材缺失或低置信数量。
- 知识快照。

存在失败、缺失必需素材或版本不一致时禁止确认，并给出唯一修复动作。

确认成功后：

```text
StoryboardVersion.status = confirmed
ContentItem.stage = storyboard_confirmed
Primary action = 进入生产
```

### 6.5 生产交接弹层

宽度 `720px`，包含去向选择、必要配置和固定确认摘要。

#### 去向一：生成单条视频

- 默认选项。
- 自动批次名：`{内容标题} · 单条生产`，可编辑。
- 使用当前账号默认 AI 配方和发布约束。
- 确认后创建 `ProductionBatch` 与一个 `BatchEntry`，导航到批量生产详情。

#### 去向二：加入现有批次

- 只列当前账号、尚未完成且允许添加条目的批次。
- 每行显示批次名称、阶段、条目数、配方摘要和可接收状态。
- 已进入不可追加阶段的批次置灰并说明原因。

#### 去向三：创建新批次

- 字段仅包含批次名称、目标节奏和 AI 配方来源。
- 高级模型与成本配置通过“更多设置”进入 Detail Panel，不在交接弹层堆叠。

#### 固定确认摘要

```text
内容：三步整理混乱提示词
脚本：v3 · 已采用
分镜：v2 · 已确认
知识：快照 2026-07-19 09:30
去向：本周 AI 工具拆解
```

底部动作：取消、确认并进入生产。

## 7. 批量生产页面

### 7.1 页面目标

批量生产页负责队列编排和执行追踪，不重复编辑脚本或分镜正文。用户必须能回答：

1. 这个批次包含哪些内容？
2. 每条内容来自哪个选题？
3. 使用哪版脚本和分镜？
4. 当前阻断在哪里？
5. 输出进入了哪里？

### 7.2 顶部批次区

- 左侧：批次切换器、批次名称、阶段、内容数。
- 中间：整体阶段流和进度。
- 右侧：新建批次或当前阶段的取消 / 重试动作。
- “当前批次”不再写成不可切换的静态标题。

### 7.3 队列工具栏

- 搜索：内容标题、选题标签。
- 阶段：全部、脚本、分镜、生成、合成、待发布。
- 状态：全部、阻断、运行中、待确认、已完成。
- 来源：已确认内容、AI 主题、固定脚本、已有素材。
- 默认排序：阻断优先，其次运行中，再按更新时间。

### 7.4 批次队列行

宽屏表格列：

| 列 | 内容 |
| --- | --- |
| 内容 | 标题、短编号、来源 |
| 选题 | 已就绪 / 缺失，点击返回脚本与选题 |
| 脚本 | `v3 已采用` / `待采用` / `缺失` |
| 分镜 | `v2 已确认` / `1 个异常` / `缺失` |
| 生产 | 当前节点、进度或阻断原因 |
| 输出 | 成片版本或尚未生成 |
| 动作 | 一个与当前状态匹配的主动作 |

行尾动作映射：

- 创作未完成：`继续创作`。
- 生产运行中：`查看进度`。
- 节点失败：`修复`。
- 待确认：`预览`。
- 已完成：`打开成片`。

点击非动作区域打开右侧 Detail Panel，展示不可变引用、AI 节点、日志和输出资产。

### 7.5 新建批次来源

第一步来源卡固定为：

1. 已确认内容。
2. AI 主题。
3. 固定脚本。
4. 已有素材。

“已确认内容”展示可多选 `ContentItem` 列表，并标记脚本 / 分镜是否就绪。未确认内容可以看到但不能选择，提供“继续创作”动作。

AI 主题、固定脚本和已有素材创建批次时，也必须为每条输入创建或关联一个 `ContentItem`；批次内阶段仍遵循选题、脚本、分镜、生成、合成、待发布。

### 7.6 单项批次标识

只有一个 `BatchEntry` 的批次显示低对比 `单条生产` 标签，页面结构和功能不变，不为其创建专用页面或不同状态机。

## 8. 视频拆解页面

### 8.1 页面骨架

保持左侧任务列表、右侧阶段与结果的主从结构。右侧结果从三标签改为四标签：

```text
脚本文案 | 关键词 | 关键帧 | 内容结构
```

### 8.2 脚本文案结果

每个段落行显示：

- 起止时间。
- 转写正文。
- 段落作用：Hook、展开、证据、CTA 等。
- 置信状态。
- 选择框。

演示数据必须标记 `demo: true`，推荐使用：

| 时间 | 正文 | 作用 |
| --- | --- | --- |
| 00:00–00:04 | 提示词越堆越长，通常不是信息不够，而是结构失控。 | Hook |
| 00:05–00:18 | 先写目标，再把约束拆成格式、语气和禁区。 | 方法 |
| 00:19–00:31 | 最后放入一个能直接验证结果的例子。 | 证据 |
| 00:32–00:36 | 先整理结构，再继续加内容。 | CTA |

选择段落后可执行：创建脚本草稿、追加到现有脚本新版本、保存为文档资产。

### 8.3 关键词结果

关键词分组固定为：

- 主题。
- 人物 / 对象。
- 视觉元素。
- 动作。
- 语气。

每个关键词 Chip 显示关键词、权重和命中次数；点击后在右侧或下方显示证据时间点和对应句子。

演示数据：

| 分组 | 关键词 | 权重 | 证据 |
| --- | --- | --- | --- |
| 主题 | 提示词整理 | 0.94 | 00:01、00:33 |
| 对象 | 目标与约束 | 0.88 | 00:07、00:12 |
| 视觉 | 前后对比 | 0.82 | 00:20、00:27 |
| 动作 | 拆分 | 0.79 | 00:09 |
| 语气 | 直接、教学 | 0.76 | 全段 |

选择关键词后可写入选题标签、策划简报或账号知识库。

### 8.4 关键帧结果

如果任务存在真实提取帧，使用三列卡片展示：

- 真实帧缩略图。
- 时间码。
- 画面摘要。
- 主体与构图。
- 可复用用途。

如果没有真实帧，不使用纯色占位卡或伪缩略图。显示稳定空态：

- 标题：`尚未生成关键帧预览`。
- 说明：`脚本和结构结果已保留，可重新运行关键帧提取。`
- 主动作：`提取关键帧`。

真实帧可写入分镜参考或当前账号图片资产。

### 8.5 内容结构结果

使用带时间比例的横向结构条，不再只是四个等宽标签：

```text
Hook 0–4s | 方法 5–18s | 证据 19–31s | CTA 32–36s
  11%           39%            36%           14%
```

选中结构段后显示：

- 结构作用。
- 起止时间和占比。
- 对应脚本文案。
- 对应关键词。
- 对应关键帧（真实存在时）。

结构可复制为新选题结构模板或脚本大纲。

### 8.6 应用结果弹层

第一层选择动作：

- 创建新选题。
- 创建脚本草稿。
- 追加脚本新版本。
- 创建分镜新版本。
- 写入账号知识库。
- 导入图片 / 文档资产。

第二层显示具体影响预览，例如：

```text
将创建：1 个新选题
将带入：4 个结构段、5 个关键词
来源：对标口播 · 三段式讲解 / 00:00–00:36
不会覆盖：现有脚本与分镜
```

目标是现有内容时，必须选择 `ContentItem` 并显示将创建的版本号。默认不覆盖。

提交成功后提供一个明确去向动作：`打开新选题`、`打开脚本版本`、`打开分镜版本` 或 `查看知识条目`。

## 11. 原型状态与动作边界

### 11.1 状态模块

- 新建选题失败。
- AI 候选生成失败或超时。
- 脚本生成、保存和采用失败。
- 分镜生成、局部重试和确认失败。

- 拆解结果应用失败。
- 内容库加载、筛选、详情和文件修复失败。

每个异常使用 `prototypeLogger.error` 记录账号、对象、动作和错误；UI 显示中文摘要、影响和重试，不只输出控制台。

## 14. Light / Dark

- 使用同一 DOM 结构和状态语义，只替换令牌。
- 创作链完成、当前、异常状态在两主题下都有足够对比度。
- 关键帧真实图片上方不叠加依赖主题颜色的装饰层。
- 无预览资产使用主题中性表面与类型图标。
- 选中、Hover、Focus、Disabled 和 Running 状态在两主题下都可区分。

## 15. 可访问性

- 创作链使用有序列表语义，当前阶段设置 `aria-current="step"`。
- 新建选题来源和拆解结果标签使用 `role="tablist"`、`role="tab"` 与 `aria-selected`。
- Modal 使用 `role="dialog"`、`aria-modal="true"`，打开后聚焦标题或首个字段，关闭后回到触发按钮。
- 表单错误与字段通过 `aria-describedby` 关联。
- 批次状态和内容库状态不能只靠颜色。
- 所有卡片动作可由键盘进入；卡片本身不嵌套多个不可达按钮。
- `Esc` 关闭最上层浮层；存在未保存状态时先确认。
- Reduced Motion 关闭位移、缩放和循环动画。

## 20. 规格审批门

本规格批准后才可进入原型实现。批准意味着接受：

1. `ContentItem` 作为选题、脚本和分镜的统一主对象。
2. 单条生产使用单项批次，不建立第二套链路。
