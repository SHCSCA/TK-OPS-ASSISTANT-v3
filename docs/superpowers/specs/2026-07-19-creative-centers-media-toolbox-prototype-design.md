# TK-OPS 创作前链路与媒体工具箱交互原型设计规格

**状态：** 已完成  
**日期：** 2026-07-19  
**计划批准：** 用户于 2026-07-19 回复“批准计划”  
**规格批准：** 用户于 2026-07-19 回复“批准规格”  
**目标平台：** Windows PC 桌面应用，不设计手机、平板或触屏交互  
**视觉基线：** 当前已确认的「极简生产台」账号工作区原型  
**实现边界：** 只修改 `docs/prototypes/tk-ops-account-workspace/` 及相关原型测试，不修改生产 Desktop、Runtime、数据库或真实接口

## 1. 设计结论

本轮补回的是创作前链路，不是旧制作驾驶舱：

1. “内容计划”升级为可完成选题和脚本版本的“脚本与选题”。
2. “分镜规划”恢复为脚本之后、批量生产之前的明确工作面。
3. “视频拆解”恢复为可导入、可查看标准结果、可选择性回流的创作入口。
4. 新增“媒体工具箱”，承接六种轻量媒体任务，所有输出回到当前账号内容库。
5. AI 剪辑工作台、多轨时间线和逐帧剪辑仍不进入产品。

默认界面只展示当前对象、主内容、状态和一个主动作。策划字段、模型参数、版本、日志和技术证据继续通过折叠区、Modal 或 Detail Panel 渐进披露。

## 3. 范围

### 3.1 本轮必须实现

- 十个账号级导航入口和两处分隔线。
- 脚本与选题：选题池、策划简报、脚本正文、AI 动作、版本和进入分镜。
- 分镜规划：脚本结构对照、镜头列表、生成 / 重生成、版本和进入批量生产。
- 视频拆解：来源选择、阶段状态、三类结果、失败恢复和选择性回流。
- 媒体工具箱：六个 P0 工具、统一四步向导、权利确认和任务详情。
- 工具输出进入当前账号内容库，并显示来源工具和版本。
- 所有新增数据、任务、抽屉和选择状态随账号切换。
- Light / Dark、`1440×900`、约 `1180×760` 和 `960×640` 最小 PC 窗口。
- 加载、空、正常、受限、排队、运行、正在取消、失败、完成和重试状态。

### 3.2 本轮不实现

- 真实链接下载、去水印、FFmpeg 执行、文件选择、转录或视频解析。
- 真实 Provider、FFprobe、平台授权、发布或媒体文件输出。
- AI 剪辑工作台、Timeline、轨道、逐帧剪辑、专业调色或特效。
- 手机端、团队协作、经营数据、订单、商品或收益。
- 绕过登录、DRM、付费墙、访问控制或平台安全机制。

## 5. 全局壳层

### 5.1 Sidebar

- 展开宽度保持 `248px`，单项高度 `40px`，入口全部可见时不滚动整页。
- 定位与知识之后、批量生产之后使用低对比 `1px` 分隔线。
- 不显示“创作”“资产”等持续分组标题，避免文字噪音。
- `1180px` 以下收缩为 `76px` 图标栏；每项保留 `aria-label` 和 Tooltip。
- `760px` 高度不足时，仅中部导航区域独立滚动，品牌、系统设置和账号切换器固定。
- 账号切换完成后，恢复目标账号最近页面；如果该页面数据不可用，进入对应空态而不是自动跳回工作台。

### 5.2 Top Bar

- 左侧：页面标题、演示标记、当前账号短说明。
- 右侧：Runtime 状态、主题切换和页面唯一主动作。
- 主动作映射：
  - 脚本无正文：`AI 生成脚本`
  - 脚本已采用：`进入分镜`
  - 分镜为空：`AI 生成分镜`
  - 分镜已采用：`进入批量生产`
  - 视频拆解：`导入视频`
  - 媒体工具箱：无全局主动作，工具卡自身是入口
- 页面不得同时显示两个紫色主按钮。

### 5.3 Detail Panel

- 宽屏 `360px`，紧凑窗口使用覆盖式抽屉。
- 根据页面承载脚本版本、AI 作业、镜头字段、拆解阶段、媒体任务或输出详情。
- Panel 切换对象时更新标题与上下文，不能保留上一账号或上一页面详情。
- `Esc` 关闭；关闭后焦点回到触发控件。

## 6. 脚本与选题

### 6.1 宽屏布局

```text
┌ 选题与简报 300px ┐ ┌ 脚本工作面 flex ┐ [按需 Detail Panel]
│ 搜索 / 筛选       │ │ 版本状态 / 模式   │
│ 选题列表           │ │ 结构化预览或原文 │
│ 简报摘要           │ │ 选中内容 AI 动作 │
└──────────────────┘ └──────────────────┘
```

左侧只显示：

- 选题搜索与内容支柱筛选。
- 当前账号 4–6 条演示选题。
- 当前选题的主题、目标用户、时长和风格摘要。
- “展开完整简报”进入 Modal 或折叠区。

主工作面：

- 顶部显示脚本标题、`草稿 / 已保存 / 已采用 / 已过期` 和修订号。
- 两个模式标签：`结构化预览`、`原文编辑`。
- 结构化预览固定为钩子、主体段落、CTA 三类段落，不模拟复杂文档编辑器。
- 原文编辑使用单一文本区，保存后生成新演示修订。
- 选择文本后出现低噪音浮动 AI 动作：改写、缩短、扩写；其余进入更多菜单。

### 6.2 完整策划简报

字段：

- 视频主题
- 产品 / 服务
- 目标用户
- 视频目的
- 视频时长
- 账号定位版本
- 视频风格
- 拍摄条件
- 语言要求
- 禁止内容

简报默认继承当前账号定位和知识规则。修改后标记“本脚本覆盖”，不反向修改账号配置。

### 6.3 版本与 AI 作业

点击版本状态打开 Detail Panel：

- 当前采用修订、最近保存时间和基于的知识快照。
- 版本列表：修订号、来源、时间、状态。
- AI 作业：能力、模型简称、状态、耗时和错误。
- 动作：比较、采用、恢复、复制；一次只显示一个推荐主动作。

### 6.4 主要交互

1. 选择选题后切换当前 `ContentItem`；若正文未保存，先提示保存、放弃或取消。
2. 点击 AI 生成脚本，进入运行状态，正文区域显示轻量 Skeleton 和可取消状态。
3. 生成完成后显示草稿，用户编辑并保存新修订。
4. 采用脚本后主动作变为“进入分镜”。
5. 进入分镜时传递 `contentItemId` 和已采用 `scriptRevision`。

### 6.5 状态

- 空：没有选题；主动作“建立选题”。
- 空正文：已有选题但没有脚本；主动作“AI 生成脚本”。
- 运行：生成中，可取消；不显示假进度百分比。
- 错误：显示中文原因、受影响对象、重试和日志。
- 未保存：页面标题旁显示小圆点；切页和切账号触发守卫。
- 已采用：显示绿色文字状态，进入分镜可用。

## 7. 分镜规划

### 7.1 宽屏布局

```text
┌ 脚本结构 260px ┐ ┌ 分镜镜头列表 flex ┐ [镜头 Detail Panel]
│ 修订与同步状态  │ │ 镜头 01            │
│ 段落锚点        │ │ 镜头 02            │
│ 文案摘要        │ │ ...                │
└────────────────┘ └────────────────────┘
```

### 7.2 脚本结构对照

- 显示已采用脚本修订和知识快照。
- 段落锚点与镜头卡双向高亮。
- 当前脚本更新时显示“脚本已更新到 vN，当前分镜基于 vM”。
- 用户选择“同步最新脚本”时明确提示未保存镜头修改会被覆盖。

### 7.3 镜头卡

固定展示：

- 镜头编号与对应脚本段落。
- 画面摘要。
- 旁白 / 字幕摘要。
- 时长。
- 景别 / 运动短标签。
- 素材状态：已有、待生成、缺失或失败。

卡片动作：选择、上移 / 下移、镜头级重生成、更多。高级 Prompt、Provider、素材来源和版本进入 Detail Panel。

### 7.4 主要交互

1. 无采用脚本时显示阻断空态和“返回脚本与选题”。
2. 点击 AI 生成分镜，创建演示作业并显示运行状态。
3. 选择镜头打开 Detail Panel，可修改画面摘要、时长、景别、运动和素材策略。
4. 保存生成新分镜修订；采用后主动作变为“进入批量生产”。
5. 进入批量生产时建批向导预填当前内容对象、脚本修订和分镜修订。

### 7.5 状态

- 无脚本、无分镜、生成中、正常、脚本过期、镜头失败、保存失败和已采用。
- 镜头失败只突出对应卡片，其余镜头保持可浏览。
- 重新生成镜头不影响已成功镜头。

## 8. 视频拆解

### 8.1 默认列表

- 顶部过滤：全部、处理中、需处理、已完成。
- 表格列：视频、来源、阶段、状态、更新时间、主动作。
- 来源显示本地导入、内容库或媒体工具，不显示完整私密路径。
- 空态只显示“导入视频”和一句用途说明。

### 8.2 导入来源

点击“导入视频”打开来源选择：

1. 本地视频文件（演示文件选择）。
2. 当前账号内容库。
3. 当前账号媒体工具输出。

来源不可用时禁用并说明原因。链接输入不放在拆解页，链接下载统一从媒体工具箱完成。

### 8.3 任务详情

选中任务后主区切换为详情：

- 顶部：文件名、来源、时长、分辨率和状态。
- 五阶段：导入 / 元数据、解析 / 转录、分段、结构提取、结果确认。
- 当前运行和失败阶段突出；完成阶段低饱和。
- 点击阶段打开 Detail Panel，显示 Provider、模型、耗时、日志、失败原因和重新运行。

### 8.4 标准结果

三个标签页：

- 脚本文案：真实转录或解析文本、段落和时间范围。
- 视频关键帧：关键帧缩略图、时间点和画面摘要。
- 内容结构：钩子、主体、CTA、节奏与可复用建议。

演示数据必须标记“演示结果”。空结果不生成仿真文案或关键帧，显示准确缺失原因。

### 8.5 选择性回流

点击“应用至创作”打开确认对话框：

- 可选目标：脚本、分镜、知识库。
- 每个目标显示当前版本、将创建的新版本和影响。
- 默认不勾选覆盖已有对象；用户主动选择后才允许确认。
- 成功后给出“查看脚本”“查看分镜”中的一个上下文主动作，其余进入普通链接。

### 8.6 错误恢复

- Provider 缺失：前往 AI 能力。
- FFprobe 缺失：前往 Runtime 诊断。
- 源文件缺失：重新定位文件。
- 阶段超时 / 失败：从该阶段重试。
- 账号切换：旧账号任务继续运行，但从当前视图移除。

## 9. 媒体工具箱

### 9.1 工具目录

六张固定工具卡：

| 工具 | 简短说明 | 图标语义 | 原型能力状态 |
| --- | --- | --- | --- |
| 视频下载 | 保存已授权公开链接素材 | 下载 | 演示可用 |
| 视频去水印 | 清理自有或获授权素材水印 | 橡皮 / 清理 | 演示可用 |
| 转码压缩 | 转换格式、分辨率或体积 | 转换 | 演示可用 |
| 音频提取 | 从视频生成 MP3 或 WAV | 音频 | 演示可用 |
| 封面 / 关键帧 | 提取封面或关键画面 | 图片 | 演示可用 |
| 比例裁切 | 生成 9:16、1:1、16:9 版本 | 裁切 | 演示可用 |

卡片不显示“成功率”“累计处理”等假数字。

### 9.2 统一四步向导

步骤 1：输入

- 下载：公开链接 URL。
- 其他工具：本地文件或当前账号内容库资产。

步骤 2：配置

- 下载：清晰度优先、音视频合并、输出格式。
- 去水印：区域裁切、遮罩覆盖、画面修复三种演示策略；通过预览区域选择水印位置。
- 转码压缩：格式、分辨率和质量预设。
- 音频提取：MP3 / WAV、音质和声道。
- 关键帧：场景检测或固定间隔、最大数量。
- 比例裁切：9:16 / 1:1 / 16:9、居中或主体优先。

步骤 3：权利确认

- 固定复选框：“我确认该素材为本人所有、公共领域或已获得处理与保存授权。”
- 下载额外说明：不支持需要登录、DRM、付费墙或访问控制的来源。
- 去水印额外说明：不得用于隐藏来源、冒充原创或规避版权标识。
- 未勾选时不能继续。

步骤 4：执行确认

- 当前账号、输入摘要、配置摘要、输出目录和“演示任务”标记。
- 创建任务后关闭向导并打开任务 Detail Panel。

### 9.3 最近任务

表格列：工具、输入、状态、进度 / 完成时间、主动作。

状态与动作：

- 排队中：取消。
- 运行中：取消、查看详情。
- 正在取消：无重复动作。
- 失败：重试；日志进入详情。
- 完成：打开输出或导入内容库。

演示完成后生成当前账号的新内容库资产，并标记：源资产、工具、演示版本、输出格式和权利确认。

### 9.4 工具详情边界

- 页面和向导不得显示 shell 命令、FFmpeg 参数、下载器参数或 Provider 密钥。
- 依赖不可用时工具卡显示“需配置”，点击后进入稳定说明和系统诊断入口。
- 原型不声称支持具体第三方平台或真实下载成功。

## 10. 跨页主链

### 10.1 从零创作

```text
脚本与选题：选择选题 -> 生成 / 编辑 -> 采用脚本
-> 分镜规划：生成 / 校对 -> 采用分镜
-> 批量生产：带入脚本和分镜版本 -> 生成媒体 -> 自动合成
-> 内容库 -> 发布 -> 复盘
```

### 10.2 参考视频创作

```text
媒体工具箱：下载已授权素材或导入本地视频
-> 视频拆解：解析 -> 查看标准结果 -> 选择性回流
-> 脚本与选题 / 分镜规划
-> 批量生产
```

### 10.3 快速媒体处理

```text
内容库 / 本地文件
-> 媒体工具箱
-> 四步向导
-> 任务详情
-> 输出进入当前账号内容库
```

## 11. 账号隔离

每个演示账号独立持有：

- `contentItems`
- `scripts`
- `storyboards`
- `videoDeconstructions`
- `mediaToolTasks`
- 工具输出资产

切换账号必须清除：

- 当前选题、脚本编辑草稿、选中镜头、拆解任务、结果标签、工具向导和任务 Detail Panel。
- 页面级筛选和临时输入。

未保存脚本或分镜修改存在时，先显示保存 / 放弃 / 取消；媒体长任务不因切换账号而取消。

## 12. 原型数据结构

```text
AccountWorkspace
├── contentItems[]
│   ├── scriptVersions[]
│   └── storyboardVersions[]
├── videoDeconstructions[]
│   ├── stages[]
│   └── result
├── mediaToolTasks[]
└── library[]
```

关键字段：

- `ContentItem`：id、topic、pillar、brief、scriptRevision、storyboardRevision、status。
- `ScriptVersion`：revision、content、structure、source、knowledgeSnapshot、job、adopted。
- `StoryboardVersion`：revision、basedOnScriptRevision、scenes、job、adopted。
- `VideoDeconstruction`：source、metadata、stages、result、appliedTargets。
- `MediaToolTask`：toolId、input、rightsConfirmation、config、status、progress、outputAssetId、error、logId。

复制或更新演示对象必须保持不可变更新，避免跨账号共享数组引用。

## 14. 配置、日志与错误

## 15. 响应式与主题

### 15.1 `1440×900`

- Sidebar `248px`。
- 脚本与分镜使用左栏 + 主工作面；Detail Panel 打开时缩小主区但不压缩到不可读。
- 视频拆解列表与结果采用主从切换，不做三栏参数墙。
- 工具卡 3 列，最近任务全列显示。

### 15.2 `1180×760`

- Sidebar `76px`。
- 脚本选题栏折叠为顶部按钮；分镜脚本栏折叠。
- 视频拆解任务列表和结果不并排。
- 工具卡 3 列或 2 列，最近任务隐藏输入摘要。
- Detail Panel 覆盖主区。

### 15.3 `960×640`

- 仍使用 PC 图标 Sidebar，不出现移动导航。
- 工具卡两列；脚本和分镜保持单主列。
- Modal 最大高度限制并内部滚动，底部主动作固定可见。

Light / Dark 共享结构、尺寸和状态语义；只替换令牌，不为深色主题单独改布局。

## 16. 可访问性

- 十个导航按钮有可访问名称、当前项状态和键盘焦点。
- 标签页使用正确 `tablist / tab / tabpanel` 语义。
- 工具卡是按钮或链接，不使用不可聚焦容器模拟点击。
- 权利确认有完整标签、错误提示和禁用原因。
- 任务进度和状态变化有文字，不只依赖颜色或动画。
- Modal 和 Detail Panel 管理焦点；`Esc` 可关闭，关闭后恢复触发点。
- Reduced Motion 下关闭页面位移、循环动画和不必要的缩放。

## 17. 自动化测试

至少覆盖：

1. 导航包含十个账号入口，并且不含 AI 剪辑工作台。
2. 脚本采用后“进入分镜”可用；未采用时阻断。
3. 脚本修订更新后，分镜显示修订不一致提示。
4. 镜头失败可局部重试，不重置其他镜头。
5. 视频拆解三类结果和选择性回流目标正确。
6. Provider / FFprobe / 源文件缺失显示正确恢复入口。
7. 六个工具均使用统一四步向导。
8. 下载与去水印未确认权利时不能创建任务。
9. 任务取消、失败、重试、完成和输出入库更新一致。
10. 切换账号后脚本、分镜、拆解、工具任务和输出不串数据。
11. Light / Dark 与宽屏 / 紧凑窗口关键布局类存在。
12. “内容计划”旧入口不再出现，旧能力进入脚本与选题。

## 18. Design QA

必须捕获并组合比较：

- 当前已确认工作台与新版十入口工作台。
- 当前内容计划与新版脚本与选题。
- 生产脚本页面结构参考与新版低噪音脚本工作面。
- 生产分镜页面结构参考与新版无时间线分镜工作面。
- 生产视频拆解能力结构与新版账号级拆解页面。
- 媒体工具箱 Light / Dark、`1440×900` 与 `1180×760`。

P0：断链、数据串号、Modal 无法退出、权利确认可绕过、任务无恢复。  
P1：导航拥挤、工作面被参数墙污染、关键内容遮挡、紧凑窗口整体横向滚动。  
P2：间距、图标、Hover、Focus、文本截断和动效细节。

P0 / P1 必须清零后交付。

## 19. 验收标准

1. 用户能从 Sidebar 直接进入脚本与选题、分镜规划、视频拆解和媒体工具箱。
2. 脚本与选题完成选题 -> 生成 / 编辑 -> 保存 -> 采用 -> 进入分镜。
3. 分镜规划完成脚本对照 -> 生成 / 校对 -> 保存 -> 采用 -> 进入批量生产。
4. 视频拆解完成来源选择 -> 阶段 -> 三类结果 -> 选择性回流，并有失败恢复。
5. 六个工具完成输入 -> 配置 -> 权利确认 -> 执行确认 -> 任务详情 -> 输出入库演示。
6. 下载和去水印不能绕过权利确认，也不宣称支持受保护来源。
7. 页面没有 Timeline、轨道、参数墙或持续可见的长说明。
8. 所有新对象和任务严格随账号切换，后台任务不因切换而取消。
9. Light / Dark、`1440×900`、`1180×760` 和 `960×640` 可用。
10. 原型模块拆分清晰，新增交互有测试，生产代码和真实接口保持不变。
