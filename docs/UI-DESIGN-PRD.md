本文取代旧的 16 页制作驾驶舱和 AI 剪辑工作台设计。当前界面围绕账号、创作对象、批次、异常和下一步动作组织，不再围绕 Timeline 组织；脚本、分镜和视频拆解使用明确工作面，但不恢复剪辑器视觉语言。

## 2. 体验目标

用户进入任意页面时，应在数秒内确认：

1. 当前是哪个账号工作区。
2. 当前脚本、分镜、拆解任务、媒体任务或批次处于哪个阶段。
3. 是否存在需要处理的异常。
4. 最推荐的下一步动作是什么。

界面必须低文字密度、低视觉噪音。通过留白、对齐、层级、状态色和渐进披露表达结构，不用长段说明、指标卡墙、重复标签或持续可见的帮助文本。

## 3. 视觉方向：极简生产台

### 3.1 气质

- 专业、克制、明亮、可靠。
- 像内容生产控制台，不像经营后台或专业剪辑软件。
- 深海军蓝 Sidebar 提供稳定边界；主工作区以白色和浅灰为主。
- 青色表达品牌、选择和阶段进度；紫色仅表达主要 AI 生成动作。
- 异常使用局部危险色，不把整页染红。

### 3.2 基准画布

- 宽屏设计基准：`1440 × 900`，视觉参考可扩展到 `1440 × 1024`。
- 紧凑 PC 窗口：约 `1180 × 760`。
- 最小 PC 窗口：`960 × 640`。
- 不设计手机、平板、触屏手势或移动端导航。

## 4. 全局壳层

正常工作态固定使用：

`Account Sidebar + Account Top Bar + Content Host + Optional Detail Panel + Status Feedback`

### 4.1 Sidebar

- 展开宽度：`248px`；紧凑窗口收缩为 `76px` 图标栏。
- 背景：深海军蓝，导航使用单列纵向布局。
- 顶部显示真实 TK-OPS 品牌标记与产品名。
- 中部显示十个账号级入口：工作台、定位与知识、脚本与选题、分镜规划、视频拆解、批量生产、内容库、媒体工具箱、发布、复盘。
- 定位与创作、创作与资产之间使用两条低对比分隔线，不增加持续可见的长分组标题。
- 当前项使用低饱和青色底、左侧细指示和高对比文字。
- 底部先显示系统设置，再显示账号切换器。
- 不显示旧后台页面分组、长描述、统计数字或禁用项列表。

### 4.2 账号切换器

- 固定在 Sidebar 左下角，是工作区边界而不是筛选控件。
- 收起态显示账号头像、名称、平台与展开图标。
- 弹层向上展开，包含搜索、最近账号、完整账号列表、添加账号和管理入口。
- 账号项最多展示头像、名称、定位短标签和连接状态。
- “添加账号”打开六步创建向导；“管理账号”进入系统级账号管理页，不能停留在无反馈点击。
- 切换中显示轻量遮罩或局部 Skeleton，并阻止重复点击。
- 切换后主内容、导航状态、Detail Panel 与任务反馈一次性更新，避免混合账号内容。

### 4.3 Top Bar

- 高度：`64px`。
- 左侧显示当前账号和当前页面名称；账号名称可作为二级文本。
- 右侧只保留 Runtime / 工作区健康状态、必要通知和页面主动作。
- 工作台主动作固定为“新建批次”；脚本、分镜、拆解和工具箱各保留一个与当前任务相关的紫色主动作。
- 不重复显示 Sidebar 已有的信息，不放置多组图标按钮。

### 4.4 Content Host

- 背景：低对比浅灰 Canvas。
- 最大内容宽度按页面需要控制，工作台与批次页可全宽。
- 宽屏水平内边距 `28–32px`，紧凑窗口 `20px`。
- 页面主体不整体横向滚动；表格、日志和内容墙使用局部滚动。

### 4.5 Detail Panel 与持续反馈

- Detail Panel 仅在选中异常、脚本版本、分镜镜头、拆解阶段、媒体任务、内容版本、知识来源或发布任务时按需打开。
- 宽屏宽度 `360px`；紧凑窗口使用右侧覆盖抽屉，不挤压主表格。
- 持续任务状态优先放在对应批次行和轻量底部状态条，不保留高噪音常驻控制台。
- Toast 只承载短反馈；失败原因、日志和恢复动作必须留在稳定容器中。

### 4.6 创作链头部

- 脚本与选题、分镜规划和批量生产内容详情复用低高度创作链头部：选题、脚本、分镜、生产、成片。
- 头部显示当前 `ContentItem` 标题、五阶段状态和当前阶段的一个主动作，不重复侧栏导航。
- 未开始、进行中、待确认、已确认、异常和已完成同时使用图标、文字与颜色表达。
- 来源、版本、知识快照和批次引用进入 Detail Panel，不在头部堆叠说明。
- 紧凑窗口允许阶段区域局部横向滚动，标题和主动作保持可见。

## 5. 导航与页面模板

### 5.1 工作台

首屏只保留四个区块：

1. 当前账号与主动作。
2. 六阶段生产流：选题、脚本、分镜、生成、合成、待发布。
3. 当前批次紧凑表格。
4. 待处理异常列表。

阶段流用于理解和筛选，不做大数字仪表盘。批次表格列控制在名称、阶段、进度、更新时间和主动作。异常区只显示问题、影响对象和恢复动作。

### 5.2 定位与知识

- 顶部显示定位短摘要、当前版本和“编辑定位”。
- 主体使用来源列表，不使用指标卡墙。
- 来源行包含类型、名称、索引状态、最近更新和更多操作。
- 规则、禁用词、钩子、CTA 和模板以分区或标签页渐进披露。
- 缺失、过期、索引失败和冲突状态就地显示影响与修复入口。

### 5.3 脚本与选题

- 顶部先显示当前内容的创作链头部；没有内容时，唯一紫色主动作是“新建选题”。
- 默认使用“选题 / 简报摘要 + 脚本工作面”的双栏布局，不把全部策划字段同时铺开。
- 左侧显示选题池、当前选题、内容支柱与策划简报摘要；完整简报进入折叠区或 Detail Panel。
- 中间脚本工作面支持结构化预览与原文编辑两种模式，并明确当前采用版本。
- 顶部只保留一个紫色主动作：无脚本时为“AI 生成脚本”，已有脚本时为“确认脚本并进入分镜”。
- AI 改写、缩短、扩写、变体和标题建议作为选中文本或更多菜单动作，不形成按钮墙。
- 版本轨迹、AI 作业、知识快照和采用 / 恢复进入右侧 Detail Panel。
- 选题可多选后批量创建脚本草稿；未形成选题时显示“建立选题”入口。
- “新建选题”打开轻量向导，来源固定为手动创建、账号定位 AI 推荐和视频拆解；手动创建默认只显示标题、内容支柱、目标受众、创作角度、目标时长和来源。
- 创建完成后立即选中新 `ContentItem`，脚本区域显示中性空态，主动作切换为“AI 生成脚本”。

### 5.4 分镜规划

- 顶部创作链头部显示当前内容、采用脚本版本和分镜确认状态。
- 左侧为已采用脚本的段落锚点，显示脚本修订号和同步状态。
- 主区使用纵向镜头列表或两列镜头板，单张镜头只显示画面摘要、旁白 / 字幕、时长、景别和素材状态。
- 顶部主动作按状态切换为“AI 生成分镜”“处理异常镜头”“确认分镜”或“进入生产”。
- “进入生产”打开交接弹层，选项固定为生成单条视频、加入现有批次、创建新批次；确认区显示内容标题、脚本版本、分镜版本、知识快照和目标批次。
- 镜头级重生成、顺序调整和保存版本就地可达；模型、Prompt、历史版本和高级字段进入 Detail Panel。
- 脚本更新时在页面顶部显示低高度同步提示，必须由用户决定同步或继续旧版本。
- 禁止时间线、轨道、逐帧裁切、磁吸和剪辑器式属性面板。

### 5.5 视频拆解

- 顶部主动作是“导入视频”，支持本地文件、当前账号内容库和媒体工具输出。
- 默认页显示项目拆解列表；选中任务后显示阶段状态与结果，不把导入表单和所有结果同时堆叠。
- 阶段流固定为导入 / 元数据、视频解析或转录、分段、结构提取、结果确认。
- 结果使用“脚本文案 / 关键词 / 视频关键帧 / 内容结构”四个标签页，同一时间只显示一种结果。
- 四类结果都使用语义表格，但列按数据类型分别设计：脚本文案为选择、时间段、正文、段落作用、置信度；关键词为选择、关键词、分类、权重、命中和证据；关键帧为选择、真实预览、时间点、镜头作用、画面摘要和可复用方向；内容结构为选择、结构段、时间、时长占比、作用、对应文案和证据关键词。
- 内容结构表上方使用低高度摘要区，显示一至两句视频特点、主要叙事类型、总时长、结构段数量和 `featureTags`；标签只表达可复用特点，不重复表格内容。
- 关键帧没有真实图片时显示稳定空态，不使用 CSS 或占位图伪造画面。表格在紧凑窗口保留主列并局部横向滚动，不产生页面级横向滚动。
- 右侧 Detail Panel 显示 Provider、模型、耗时、日志、失败证据和重新运行阶段。
- “应用至创作”打开具体影响预览，可创建选题，或写入脚本、分镜、知识库和图片资产；覆盖已有版本时明确展示影响。
- 无 Provider、FFprobe 或源文件时使用稳定错误卡，提供一个推荐修复动作和日志入口。

### 5.6 批量生产

- 顶部为批次名称、阶段、整体进度和取消 / 重试。
- 主体默认使用内容变体表格，支持按异常、阶段和状态筛选。
- 每条队列项显示选题、脚本、分镜、生产和输出的就绪状态，并可回到对应 `ContentItem`。
- 新建批次使用四步向导：输入来源、内容计划与知识快照、AI 配方、执行确认。
- 输入来源默认展示已确认内容、AI 主题、固定脚本和已有素材；图生视频作为已选图片的子模式进入。
- 固定脚本选择后显示段落、行、句子三种拆分方式及镜头草稿预览；已有素材先显示分析状态、匹配置信度和待确认替代项。
- “生成单条视频”创建单项批次并进入同一批次详情，不产生另一套单条生产页。
- 批次详情在六阶段主流程下展示脚本、分镜、图片 / 视频、TTS、字幕、合成 / BGM 和预览节点。
- 节点默认只显示名称、状态、模型简称和一个恢复动作；参数、成本、输入输出与日志进入 Detail Panel。
- 节点进度同时显示任务阶段与当前镜头，例如“生成镜头 3 / 8 · 视频”；失败时保留已完成节点并把局部重试作为唯一主动作。
- 模型参数由能力契约生成。只有适配器已接入且契约已验证时，才显示时长、比例、分辨率、负向提示、原生音频或水印；不可用字段不以禁用表单堆在页面上。
- 选择一条内容后打开右侧预览与版本详情。
- 允许镜头级重生成、切换版本、重新合成和确认成片。
- 禁止出现多轨时间线、拖拽片段、剪刀、磁吸或专业剪辑属性面板。

### 5.7 内容库

- 顶部主类型固定为全部、视频、图片、音频和文档；搜索、排序和导入保持同一工具栏。
- 次级筛选使用用途、来源和状态，覆盖成片、素材、脚本、字幕、模板、拆解输出、媒体工具输出和本地导入。
- 主体使用可响应资产墙；优先展示缩略图或类型预览、标题、类型元数据、来源、版本和状态。
- 视频、图片、音频和文档卡分别显示时长 / 分辨率、尺寸、时长 / 格式、文档子类型等匹配信息。
- 空状态引导导入或从已完成批次归档。
- 缺失本地文件必须显示修复路径和引用影响。
- 媒体工具输出显示工具、源资产、配置版本和权利确认来源；原文件与处理版本保持可追溯。

### 5.8 媒体工具箱

- 默认只显示六个 P0 工具：视频下载、去水印、转码压缩、音频提取、封面 / 关键帧提取、比例裁切。
- 工具使用统一图标卡，卡片只包含名称、一句用途和可用状态，不显示长参数说明。
- 页面下半区为最近任务表格，列控制在工具、输入、状态、进度 / 完成时间和一个主动作。
- 点击工具后打开宽屏居中向导，步骤固定为输入、配置、权利确认、执行确认。
- 下载和去水印必须在确认步骤勾选“素材为自有、公共领域或已获授权”；未确认时主动作禁用。
- 高级 FFmpeg、模型或下载器参数默认折叠；页面不暴露命令行参数。
- 运行任务进入统一任务抽屉，提供取消、重试、打开输出和导入内容库。
- 失败原因和技术详情保持在稳定任务详情中，Toast 只提示任务已创建或动作完成。

### 5.9 发布

- 顶部显示当前账号、真实执行绑定和预检状态。
- 列表区分待预检、已排期、运行中、失败、待确认和已完成。
- 发布成功只能使用真实回执；无确认时显示“待确认”。
- 失败行就地提供修复、重试和日志入口。

### 5.10 复盘

- 不做经营大屏和趋势卡墙。
- 以内容结果、证据、问题和可执行建议为列表。
- 每条建议必须指向“更新定位”“加入知识”“调整计划”之一，并由用户确认回流。
- 没有真实数据时显示连接或等待回执的中性空态。

### 5.11 账号管理

- 从左下角账号切换器进入，不出现在十个账号级主导航中。
- 页面顶部只保留标题、状态筛选和“添加账号”主动作。
- 账号列表显示身份、定位短摘要、连接 / 知识 / AI 三项就绪状态、最近使用和一个主动作。
- 点击账号进入同一系统页内的详情视图，分为概览、身份与定位、连接与工作区、知识库、AI 创作档案、发布默认值、数据与归档。
- 添加账号采用宽屏居中向导，步骤为基础身份、真实连接、定位、知识库、AI 配方、健康检查。
- 复制配置、归档和恢复必须先说明复制或影响范围；不可复制或不可逆对象不使用模糊确认文案。
- 草稿、未绑定、可用、需处理和已归档同时使用文字与颜色，不用假绿灯表示真实连接。

### 5.12 AI 与系统设置

- 系统级页面或面板，不属于账号主导航。
- 一级分区收敛为“AI 能力”“Runtime 与工作区”“日志与诊断”，避免系统配置形成菜单墙。
- AI 能力区内部使用“Provider / 模型与能力 / Prompt 模板”三个低高度二级标签；同一时间只展示一个配置面。
- Provider 页显示连接健康、适配方式、能力类型和模型数量；“添加 Provider”打开五步向导：连接类型、地址与凭据引用、网络与并发、发现 / 手动添加模型、测试并保存。密钥始终遮罩，账号页不出现密钥输入。
- Provider 详情通过右侧 Detail Panel 展示 Base URL、区域、代理、并发、超时、成本策略和连接测试。
- 模型与能力页分为模型表和能力路由表。模型表展示真实模型 ID、Provider、启用状态、已接入能力、验证状态与限制；能力路由按产品能力展示主模型、回退模型、Prompt 和修复动作。
- 模型能力矩阵区分“供应商声明”和“当前已接入”，只把已接入且已验证的交集作为可选能力；详情可查看契约来源、已知限制和最近验证时间。
- Prompt 模板页使用列表加右侧编辑器，字段包括名称、产品能力、系统提示、任务模板、变量、输出 Schema、视觉风格前缀、版本、状态和引用。新建版本、变量预览、引用关系和未保存守卫必须可完成。
- 视觉模板通过 Prompt 或账号配方的受控选择器配置，展示静态 / 图片 / 视频类型、画幅、参数摘要和真实预览；普通用户不直接编辑 HTML 或工作流 JSON。
- 账号级覆盖项必须明确标记继承来源与影响范围。
- 系统默认、账号覆盖和批次覆盖分别使用“系统默认”“账号覆盖”“本批次”短标签，不使用长段说明。

## 6. 核心组件

### 6.1 按钮

- Primary：紫色，仅用于页面唯一主动作。
- Brand：青色，用于当前阶段、确认和轻量执行。
- Secondary：白底弱边框。
- Ghost：无背景次要动作。
- Danger：只用于取消任务、删除或不可逆操作。
- 高度 `32 / 36 / 40px`，必须覆盖 Hover、Focus、Pressed、Disabled、Running。

### 6.2 状态 Chip

- 状态必须同时使用文字和颜色，不只依赖颜色。
- 运行中使用青色；完成使用绿色；排队使用中性；警告使用琥珀；失败使用红色；AI 生成使用紫色。
- 同一行最多两个 Chip，避免重复表达。

### 6.3 批次表格

- 表头高度 `40px`，内容行 `54–60px`。
- 行 Hover 只使用浅底色，不抬升整行。
- 进度条细而稳定，阶段文字比百分比更重要。
- 异常行可使用左侧危险色细线，不用整行红底。
- 行尾只保留一个主动作，其余操作进入更多菜单。

### 6.4 阶段流

- 六个阶段横向排列，使用节点、连线、阶段名和简短状态。
- 当前阶段青色高亮，AI 运行可使用小面积紫色标识。
- 完成阶段保持低饱和，不使用庆祝动画。
- 紧凑窗口允许横向局部滚动，不缩小文字到不可读。

### 6.5 空态与错误

- 空态只包含一个标题、一句影响说明和一个主动作。
- 业务空态固定区分首次使用、无数据、筛选为空、前置不足、等待外部结果和能力受限，并由当前页面真实数据与依赖推导。
- 工作台、脚本、分镜、拆解、生产、内容库、工具箱、发布、复盘和 AI 设置分别使用符合前置顺序的主动作；筛选为空只能提供“清除筛选”，不得误导用户新建对象。
- 错误卡包含中文摘要、影响对象、建议修复、重试和日志入口。
- 技术详情默认折叠，不直接展示 traceback。
- 首启与 Runtime 启动状态必须区分数据库预检、迁移中、结构不支持、恢复失败和 Runtime 就绪；迁移失败卡只提供安全恢复或查看日志动作，不允许用户绕过迁移进入工作区。

### 6.6 账号就绪状态

- 使用连接、知识、AI 三个固定小状态，不增加统计数字。
- 正常项使用低饱和图标与文字；仅异常项使用琥珀或红色并提供修复动作。
- 列表行最多显示一个显式按钮，其余动作进入更多菜单。

### 6.7 AI 配方摘要

- 默认显示配方名、脚本模型、视觉模式、视频模型、音色和继承来源。
- 高级参数放在覆盖式 Detail Panel，修改时实时标记哪些字段将形成账号覆盖。
- 配方不可用时显示缺失能力及“前往系统 AI 能力”修复入口。

### 6.8 生成节点列表

- 节点按依赖顺序纵向或横向排列，状态使用图标、文字与细进度线。
- 正常节点弱化，当前运行与失败节点突出；默认不显示完整 Prompt、JSON 或日志。
- 失败节点只给一个推荐主动作，回退模型、查看输入输出和日志放进详情。

### 6.9 脚本工作面

- 默认优先展示正文与结构，不把策划简报、版本和 AI 作业三者同时展开。
- 编辑态有明确未保存标识；账号切换、进入分镜或关闭页面时触发未保存守卫。
- 原文和结构化预览共享同一脚本版本，不维护两份互相漂移的内容。

### 6.10 分镜镜头卡

- 镜头编号、画面摘要、旁白 / 字幕、时长和素材状态构成固定信息骨架。
- 正常镜头弱化边框；选中、运行、警告和失败使用局部状态线，不整卡染色。
- 高级镜头字段在 Detail Panel 编辑，卡片不堆满表单控件。

### 6.11 拆解结果标签页

- 四个标签固定为脚本文案、关键词、视频关键帧和内容结构。
- 每个结果都显示来源状态与生成证据；结果为空时不使用仿真文本填充。
- 回流动作从结果容器发起，但最终确认在独立对话框完成。
- 表头使用真实语义，行高以正文阅读为准；选择列固定，正文最多三行并可在详情展开，权重使用数值加轻量条，证据时间点可聚焦和点击。
- 内容结构摘要与标签位于表格上方，不和任务元信息、Provider 详情混在同一视觉层。

### 6.12 媒体工具任务

- 工具目录、向导和任务详情共用一套状态与按钮语义。
- 任务状态同时使用图标、文字和进度，不只依赖颜色。
- 权利确认、源文件、输出资产和日志引用必须在详情可追溯。

### 6.13 新建选题向导

- 来源选择、必要字段、创建确认三段在同一居中弹层完成，不做长步骤条。
- 手动模式默认六个字段；AI 推荐模式先显示账号定位与知识快照，再展示可多选候选；拆解模式显示来源任务和可采用证据。
- 创建中、失败和成功必须留在弹层内稳定反馈；成功后关闭弹层并选中新内容。

### 6.14 生产交接弹层

- 三种去向使用单选卡：生成单条视频、加入现有批次、创建新批次。
- 下方固定显示采用脚本、确认分镜、知识快照和目标批次摘要。
- 批次不可接收、版本缺失或镜头异常时禁用确认，并提供唯一修复动作。

### 6.15 批次队列项

- 固定信息骨架为内容标题、来源、选题、脚本、分镜、当前生产阶段、输出和一个主动作。
- 宽屏可以表格显示；紧凑窗口隐藏来源等次要列，但必须保留脚本 / 分镜阻断状态。
- 运行中引用不可变；创作页产生新版本时只提示存在更新，不自动替换。

### 6.16 内容库资产卡

- 所有类型共用标题、类型、来源、版本和状态骨架，预览和元数据按类型差异化。
- 无真实预览时使用类型图标与中性底色，不使用假缩略图或 CSS 绘制内容。
- 点击资产卡打开 Detail Panel，展示路径、来源对象、配置版本、引用影响和恢复动作。

### 6.17 AI 配置组件

- Provider 向导宽度控制在 `720–820px`，每步只显示当前必要字段；连接测试、模型发现、保存失败和取消均在弹层内稳定反馈。
- 模型表与能力路由表沿用统一表格密度。缺失主模型或 Prompt 的路由使用局部警告和一个“配置”动作，不渲染大面积红色卡片。
- Prompt 编辑器的正文区占主宽度，变量、Schema、版本和引用进入侧栏或折叠区；测试预览只显示脱敏输入和结构化输出摘要。
- 能力参数控件由 Schema 渲染，未验证参数完全隐藏；高级适配器细节只在 Detail Panel 显示。
- 模板选择使用真实预览、类型和画幅筛选；无预览时显示中性类型图标，不生成假效果图。

- Top Bar 隐藏重复账号副文本，保留页面标题、健康状态和主动作。
- 阶段流使用局部滚动。
- 批次表格隐藏次要列，保留名称、阶段、进度和动作。
- Detail Panel 改为覆盖式抽屉。
- 异常说明截断为一行，完整信息进入详情。
- 账号管理隐藏最近使用等次要列，保留身份、三项就绪状态和动作。
- 批次向导保持单列步骤内容；AI 能力矩阵使用局部横向滚动，不压缩到不可读。
- 脚本页隐藏左侧选题摘要，改为顶部切换按钮；正文保持主区域。
- 分镜页折叠脚本段落栏，镜头卡改为单列；Detail Panel 使用覆盖抽屉。
- 视频拆解结果保持标签页，列表与结果改为主从切换，不并排挤压。
- 内容库资产墙使用至少两列，类型筛选保持横向局部滚动，Detail Panel 使用覆盖抽屉。

- 仍保持 PC 图标 Sidebar，不切换为手机底部导航。
- 页面主动作和账号切换入口始终可见。
- 禁止关键控件错位、遮挡或整体横向滚动。

## 10. 状态与真实性

- 所有页面必须覆盖加载、空、正常、错误和受限状态。
- 原型演示数据必须明确标记“演示原型”，不得伪装真实业务结果。
- 生产实现无真实数据时使用中性空态，不创建假账号、假设备、假绑定或假发布成功。
- 切换账号必须清空旧账号可见上下文，并在新账号数据就绪后一次性呈现。

## 11. 设计验收

1. 首屏没有大段说明、重复指标卡或后台式功能堆叠。
2. 用户能立即识别当前账号、当前阶段、异常和下一步动作。
3. Sidebar 有十个账号级入口，脚本与选题、分镜规划、视频拆解和媒体工具箱可直接发现，左下角账号切换器清晰可用。
4. 工作台、脚本与选题、分镜规划、视频拆解、批量生产和媒体工具箱沿用同一壳层、状态与 Detail Panel 语言。
5. 不出现 AI 剪辑工作台、多轨时间线或专业剪辑工具。
6. Light / Dark 与宽屏 / 紧凑窗口保持结构和语义一致。
7. 账号切换、建批、重试、预检等关键动作有加载、成功和失败反馈。
8. “添加账号”和“管理账号”均可完成主流程，不存在点击后无变化的断链控件。
9. 用户能在不展开高级设置的情况下理解当前 AI 配方、知识快照和生成节点状态。
10. Provider 密钥与账号配方边界清晰，默认界面没有 Pixelle 式参数堆叠。
11. 脚本与分镜工作面默认聚焦正文和镜头，不显示策划表单墙或剪辑器界面。
12. 新建选题能完成来源选择、必要信息填写、创建和进入脚本，不存在只有 Toast 的假交互。
13. 分镜确认后可生成单条视频、加入现有批次或创建新批次，并明确使用的版本。
14. 视频拆解能区分列表、阶段、四类结果和具体回流影响，错误有明确恢复入口。
15. 批次条目能展示选题、脚本、分镜、生产与输出之间的对象级关系。
16. 内容库可按全部、视频、图片、音频和文档筛选，并能继续按用途、来源和状态细分。
17. 媒体工具箱默认只展示六个工具和最近任务，权利确认、状态与输出路径清晰。
18. 数据库预检、迁移、结构不支持和恢复失败使用稳定状态容器，展示中文摘要、恢复动作与 `log_id`，不泄漏本地完整路径或 traceback。
