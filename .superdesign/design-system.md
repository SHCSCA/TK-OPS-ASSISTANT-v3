# TK-OPS Superdesign 唯一设计系统

## 1. 产品上下文

TK-OPS 是面向多 TikTok 账号内容创作者的本地优先 Windows PC 桌面应用。当前产品定位是“账号定位驱动的 AI 批量内容生产与发布工作台”，不是经营后台、团队协作系统或专业剪辑器。

账号是整个工作区的数据边界。每个账号独立拥有定位、知识库、内容计划、批次、内容库、发布配置和复盘。左下角账号切换器切换整个工作区，不是表格筛选器。

主链：

`Account -> ContentPlan -> ProductionBatch -> ContentVariant -> CompositionSpec -> RenderTask -> PublishTask`

每个账号另有独立 `PositioningProfile`、`AccountKnowledgeBase`、`BrandKit`、`DeviceWorkspace`、`ExecutionBinding` 和 `PerformanceSnapshot`。

产品不提供 AI 剪辑工作台、手动多轨时间线、拖拽裁切或复杂剪辑属性。自动合成保留成片预览、镜头级重生成、版本切换和异常重试。

## 2. 目标体验

每个画面必须让用户立即理解：

1. 当前账号。
2. 当前批次或内容阶段。
3. 待处理异常。
4. 推荐下一步动作。

采用“极简生产台”方向：低文字密度、低视觉噪音、清晰留白、稳定表格、渐进披露。禁止指标卡墙、长段说明、重复标签和后台式功能堆叠。

## 3. 平台与视口

- 仅 Windows PC 桌面应用。
- 宽屏基准：`1440 × 900`，可扩展至 `1440 × 1024`。
- 紧凑 PC 窗口：`1180 × 760`。
- 最小 PC 窗口：`960 × 640`。
- 不设计手机、平板、移动端导航或触屏手势。
- 页面主体禁止整体横向滚动；表格、阶段流和日志使用局部滚动。

## 4. 全局壳层

正常工作态：

`Account Sidebar + Account Top Bar + Content Host + Optional Detail Panel + Status Feedback`

### Sidebar

- 宽屏 `248px`，紧凑窗口 `76px` 图标栏。
- 深海军蓝背景，顶部真实 TK-OPS 品牌。
- 只显示：工作台、定位与知识、脚本与选题、分镜规划、视频拆解、批量生产、内容库、媒体工具箱、发布、复盘。
- 底部先显示系统设置，再显示左下角账号切换器。
- 当前项使用浅青背景、左侧细指示和高对比文字。

### Account Switcher

- 展示头像、账号名、平台和简洁状态。
- 弹层向上打开，包含搜索、最近账号、账号列表、添加和管理入口。
- 切换时使用局部 Skeleton 或轻量遮罩；完成后一次性更新整个工作区。

### Top Bar

- 高度 `64px`。
- 左侧页面名与当前账号；右侧健康状态和唯一主动作。
- 工作台主动作是紫色“新建批次”。

### Content Host

- 浅灰 Canvas、白色 Surface。
- 宽屏内边距 `28–32px`，紧凑 `20px`。
- 默认使用列表、表格和轻量分区，避免卡片墙。

### Detail Panel

- 只在选中异常、内容版本、知识来源或发布任务时出现。
- 宽屏 `360px`；紧凑窗口为覆盖式右侧抽屉。
- Header 显示对象和状态，中部展示证据与日志，底部展示恢复动作。

## 5. 正式入口

账号工作区十个主入口：

1. 工作台。
2. 定位与知识。
3. 脚本与选题。
4. 分镜规划。
5. 视频拆解。
6. 批量生产。
7. 内容库。
8. 媒体工具箱。
9. 发布。
10. 复盘。

系统级入口：首启与许可证向导、AI 与系统设置。账号管理在左下角切换器弹层内。

## 6. 工作台锚点

首屏只保留：

1. 账号和“新建批次”。
2. 六阶段流：选题、脚本、分镜、生成、合成、待发布。
3. 当前批次紧凑表格。
4. 待处理异常。

批次表格列：名称、阶段、进度、更新时间、主动作。异常项使用局部危险色细线和简短原因，不使用大红底。

## 7. 其他页面模式

- 定位与知识：定位短摘要 + 来源列表 + 规则分区 + 索引状态。
- 脚本与选题：选题简报 + 脚本工作区 + 版本详情 + 采用后进入分镜。
- 分镜规划：脚本大纲 + 镜头列表 + 镜头详情 + 脚本修订同步提示。
- 视频拆解：导入任务 + 标准阶段 + 脚本 / 关键帧 / 结构结果 + 选择性回流。
- 批量生产：批次头部 + 内容变体表格 + 异常筛选 + 成片预览 Detail Panel。
- 内容库：缩略图 / 列表 + 来源批次 + 版本 + 文件状态。
- 媒体工具箱：下载、去水印、转码、音频提取、封面关键帧和比例裁切；统一任务向导与合规确认。
- 发布：真实执行绑定 + 预检 + 任务状态 + 回执 / 重试。
- 复盘：内容结果 + 证据 + 可回流建议，不做经营大屏。
- 系统设置：Provider、配置总线、目录、Runtime、工作区、执行环境、日志和诊断。

### 使用规则

- 禁止粉色霓虹、大面积渐变、玻璃拟态和高强度发光。

## 9. 排版与尺度

- Sans：`Inter`, `HarmonyOS Sans SC`, `PingFang SC`, Windows 系统无衬线。
- 页面标题：`600 22px/30px`。
- 区块标题：`600 15px/22px`。
- 正文：`400 14px/22px`。
- 辅助文字：`500 12px/18px`。
- 任务 ID、路径和日志使用等宽字体。
- 基础网格 `4px`；常用间距 `8, 12, 16, 20, 24, 32px`。
- 主容器圆角 `10–12px`；控件圆角 `7–9px`。
- 阴影只用于弹层、Modal 和覆盖式 Detail Panel。

## 10. 组件

### 按钮

- Primary Violet：页面唯一主动作。
- Brand Cyan：确认或轻量执行。
- Secondary：白底弱边框。
- Ghost：次要操作。
- Danger：取消、删除和不可逆操作。
- 高度 `32 / 36 / 40px`，覆盖 Hover、Focus、Pressed、Disabled、Running。

### 批次表格

- 表头 `40px`，行高 `54–60px`。
- 进度细而稳定，阶段文字优先于百分比。
- 行尾一个主动作，其余进入更多菜单。
- Hover 只使用浅底，不抬升整行。

### 阶段流

- 六阶段横向节点和连线。
- 当前阶段青色，AI 运行使用小面积紫色。
- 紧凑窗口允许局部横向滚动。

### 状态 Chip

- 运行中青色、完成绿色、排队中性、警告琥珀、失败红色、AI 紫色。
- 同一区域避免重复 Chip。

### 空态与错误

- 空态只保留标题、一句影响说明和一个主动作。
- 错误包含中文摘要、影响对象、建议修复、重试和日志。
- 技术详情默认折叠，不展示 traceback。

## 11. 状态与交互

- 页面必须覆盖加载、空、正常、错误和受限状态。
- 长任务状态：排队中、运行中、正在取消、失败、完成。
- 账号切换、建批、取消、重试、预检和发布必须有可见状态反馈。
- `Ctrl + K` 当前账号内搜索；`Ctrl + N` 新建批次；`Esc` 关闭弹层与 Panel。
- Hover / Focus `120–180ms`；Panel `180–240ms`；页面切换轻微淡入。
- Reduced Motion 关闭位移、缩放与循环背景运动。

## 12. 紧凑窗口

- Sidebar 收缩为图标栏，账号切换器保留头像和状态。
- Top Bar 隐藏重复副文本，保留标题、健康和主动作。
- 阶段流局部滚动，批次表格隐藏次要列。
- Detail Panel 使用覆盖式抽屉。
- 在 `960px` 仍使用 PC 壳层，不切换手机导航。

## 13. 数据真实性

- 原型演示数据必须显著标记“演示原型”。
- 生产界面无真实数据时使用中性空态。
- 不伪造账号、设备、绑定、发布成功、播放量、收益或增长趋势。
- 切换账号后不得残留上一账号内容、任务视图或 AI 上下文。

## 14. Superdesign 工作流

- 当前方向已经选定为“极简生产台”，只迭代一个分支。
- 先像素级复现当前本地原型作为基线，再基于本文件、UI PRD 和已选视觉进行重构。
- 设计必须包含：左下角账号切换器、十入口 Sidebar、工作台阶段流、批次表格和异常区。
- 后续设计不得改变账号边界、页面树、颜色语义、字体、状态语言或移除剪辑工作台的决策。
- 本地原型至少支持账号切换、十入口导航、脚本采用、分镜局部重试、拆解回流、工具任务、新建批次、阶段筛选、异常重试、主题切换和宽屏 / 紧凑布局。
